## 열기

실행 중에는 http://127.0.0.1:1439 에 접속합니다.

다시 실행하려면 PowerShell에서:

```powershell
& 'C:\chatgpt\TEST_kisaki\_experiment\run.ps1'
```

이미지를 추가하거나 바꾼 뒤에는 `-Reanalyze`를 붙입니다. 내용 해시가 같은 특징은 캐시를 재사용합니다.
서버를 종료하려면 실행 터미널에서 Ctrl+C를 누릅니다. 포트 충돌 시 `-Port 1440`처럼 지정합니다.
Python 환경 재생성이 필요한 경우 Python 3.12로 `.venv`를 만들고 그 환경에서 `pip install -r requirements.txt`를 실행합니다.

## 사용

- 참조 1/3/5장 버튼 또는 왼쪽 마커스 이미지를 눌러 검색 기준을 변경합니다.
- 참조와 가까운 순서로 전체 검색 자료가 나옵니다. 선택한 참조 및 감지된 유사 원본은 제외됩니다.
- `잘못 올라온 이미지`와 `놓친 마커스`로 오류를 확인합니다.
- `정답 표시`를 끄면 일반 결과의 정답 뱃지와 정답 통계가 숨겨집니다. 오류 전용 필터는 정답을 이용하므로 블라인드 평가는 아닙니다.
- `마커스 참조로 추가`로 예시를 늘릴 수 있습니다. 정답 라벨은 사용자 폴더 기준이며 화면에서 수정하지 않습니다.
- 거리 기준선을 움직여 후보 수를 바꿉니다. 거리는 정답 확률이 아닙니다.
- 설정은 브라우저 localStorage에 저장됩니다. `처음 설정으로`로 되돌립니다.
- `현재 결과 JSON 저장`은 현재 표시된 결과와 설정을 파일로 내보냅니다.

## 2026-09-07 첫 실행 결과

CCIP `ccip-caformer_b36-24`의 공식 feature ONNX 및 metric ONNX를 사용했습니다.
공식 전처리의 384px bilinear resize 및 CLIP 정규화를 따르며, EXIF 방향과 투명 배경은 로컬에서 처리합니다.
추론은 파일명/폴더명을 사용하지 않습니다. 참조 선택과 평가에만 사용자 정답을 사용합니다.
공식 모델의 revision/파일 SHA256 및 전처리 식별자는 `models/manifest.json`에 있습니다.

특징 추출 91.84초, 다운로드 등을 포함한 총 분석 123.5초. 이미지 83장 및 제외 영상의 입력 해시는 분석 전후 일치했습니다.
동일 파일/간단한 dHash 유사 원본 검사에서 중복 쌍은 감지되지 않았습니다. crop/변형 중복까지 완전히 배제했다는 뜻은 아닙니다.

고정 참조 후보 5장을 모두 제외한 동일 평가셋(마커스 13장 + 비교 65장):

| 참조 | 상위 10장 중 마커스 | 기준선 내 마커스 | 오탐 | 놓친 마커스 |
|---|---:|---:|---:|---:|
| 1장 | 10 | 8 / 13 | 0 | 5 |
| 3장 | 9 | 10 / 13 | 1 | 3 |
| 5장 | 9 | 11 / 13 | 4 | 2 |

**화면의 실시간 검색은 현재 선택한 참조만 제외**하므로 1장을 선택하면 검색 대상 마커스가 17장이 됩니다. 위 고정 평가표는 같은 13장으로 비교하기 위해 참조 후보 5장을 항상 제외합니다.

기준선은 제작자가 이미지 쌍 평가에서 공개한 값을 그대로 적용했습니다. 여러 참조 중 최소 거리를 쓰는 이번 검색에 보정한 값이 아니므로 참조가 늘면 오탐도 늘 수 있습니다. 결과를 보고 이 평가셋에 맞춘 기준선은 독립적인 성능 검증이 아닙니다.

소규모 사용자 선정 표본이며 실사·다인 이미지·텍스트 비교 자료를 포함합니다. 다른 캐릭터나 실제 전체 라이브러리에 대한 정확도 수치로 일반화하지 않습니다.

검증: 실제 분석 프로세스 exit 0. 브라우저에서 83장 데이터 로드, 참조 1/5장 변경, 참조 추가 시 6장/검색 77장으로 변경, 초기화 시 5장/검색 78장 복구, 오탐 4장/놓친 마커스 2장 필터, 이미지 확대/닫기, 새로고침 후 참조 설정 유지 확인. 화면 배치를 직접 확인했습니다. JSON 다운로드는 버튼을 제공하지만 브라우저 다운로드 완료까지 검증하지 않았습니다.

## 파일과 출처

- `report.json`: 고정 평가와 실행 정보
- `public/data.json`: 특징 비교 거리, 정답, UI 데이터
- `input-hashes.json`: 입력 파일 무변경 확인용 해시
- `cache/`: 모델/내용 해시별 특징
- `public/thumbs/`: 파생 썸네일, 원본이 아님
- `analysis.log`: 최초 분석 로그
- 모델: https://huggingface.co/deepghs/ccip_onnx (OpenRAIL)
- 전처리 및 metric 호출 참고: https://github.com/deepghs/imgutils/blob/main/imgutils/metrics/ccip.py

실험 산출물은 이 폴더의 `.gitignore`로 Git 추적 대상에서 제외됩니다. 버전 관리/배포용 패키지가 아닙니다.
