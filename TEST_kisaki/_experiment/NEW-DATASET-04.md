# 새 에이메스 자료 — 검토 실험 재시작

사용자가 `man` 및 최상위 이미지를 교체한 뒤 같은 검토 흐름으로 새로 시작하도록 요청했습니다.

- 입력: 에이메스 17장, 비교 이미지 127장
- 기존 자료와 동일한 내용 해시의 파일 1개 존재. 완전히 독립된 평가셋이라고 주장하지 않습니다.
- 새 자료 안에서 seed 1999로 참조 후보 5장을 선택합니다. 이전 자료의 참조/반례를 이어서 적용하는 검증이 아닙니다.
- 기존 검토 데이터는 브라우저의 이전 데이터셋 키에 유지됩니다. 현재 접근한 브라우저에서는 이전 반례 4장 상태를 확인할 수 없었습니다. 사용자에게 폴더 교체가 잘못된 것이 아님을 설명하고 새 실험으로 진행했습니다.
- 기존 결과 및 화면 스냅샷: `archive/before-new-data-20260907-195142/`
- 모델, 전처리, 기본 기준선, 검토 엔진은 동일합니다. 화면의 자료 개수는 이제 분석 결과에서 읽습니다.
- 검토 결과의 localStorage 키는 모델 정보와 파일 내용/경로로 분리되므로 새 이미지에 이전 이미지 ID의 분류를 잘못 붙이지 않습니다.

현재 실측 결과: `report.json`, 브라우저: `review.html`. 원본은 읽기만 하며, 실험 내 분류만 변경합니다.
