# 에이메스 분류·검토 실험 (03)

열기: http://127.0.0.1:1439/review.html

기존 실행 명령 `run.ps1`을 그대로 사용합니다. 현재 72개 원본의 내용 해시가 이전 에이메스 분석과 같아서 CCIP를 다시 실행하지 않고 캐시된 거리 행렬을 사용했습니다.

## 시작 상태

- 시리즈 미지정 / 에이메스: 참조 5장(확정), 자동 검토 대기 20장
- 검토함: 47장. 총 72장
- 모델·전처리·공식 기준선 동일. 자동 후보 20장은 실험 정답상 에이메스 14장 + 비교 6장
- 이전 검색 화면과 설정은 `search-baseline.html` 및 이전 localStorage 키에 유지됩니다.
- 이전 파일 스냅샷: `archive/aimes-search-20260907-193237/`

## 검토 순서

1. 에이메스 / 검토 대기에서 잘못 들어온 이미지를 선택합니다. 기본 정렬은 참조와 덜 가까운 이미지부터입니다. `오탐만 · 정답 기준`을 고르면 이번 자료의 정답으로 필터링해 확인할 수도 있습니다.
2. 캐릭터를 알면 `정답 폴더로 수정`을 누릅니다. 대화상자 안에서 새 캐릭터 폴더도 만들 수 있습니다. 시리즈를 만들거나 기본 시리즈 이름을 바꾸는 기능은 왼쪽에 있습니다.
3. 정답으로 수정하면 해당 이미지는 목적지에서 확정되고, 이전 캐릭터의 반례가 됩니다. 목적지 참조는 자동 추가하지 않습니다.
4. 어느 캐릭터인지 몰라도 기존 후보가 틀렸으면 `이 캐릭터 아님`을 누릅니다. 반례로 기록하고 보류합니다. 단순 `보류`는 반례를 만들지 않습니다.
5. 반례를 이용해 다른 미확인 후보가 갱신됩니다. 참조보다 반례에 더 가까우면 검토함으로 돌아갑니다. 확정·보류 항목은 보호합니다.
6. 잘못 섞인 이미지를 고른 뒤 남은 후보를 선택 승인 또는 `표시된 N장 모두 승인`으로 확정합니다. 선택/승인은 현재 위치와 필터로 표시된 전체 이미지 범위에만 적용합니다.
7. 확정 탭에서 특징이 잘 보이는 이미지에 `참조로 등록`을 누릅니다. 참조를 등록/해제하면 미확인 후보가 다시 계산됩니다. 참조가 없는 새 캐릭터는 자동 추천되지 않습니다.
8. `마지막 작업 되돌리기`는 최신 작업부터 되돌립니다. 최대 40개. 오래된 자동 분류를 나중 수정 위로 덮어쓰는 임의의 과거 작업 취소는 제공하지 않습니다.

보류 항목은 보류 화면에서 선택 후 `다시 검토`로 풀 수 있습니다. 잘못 알려준 반례는 되돌리거나 올바른 캐릭터로 다시 수정하면 해당 캐릭터에 대한 부정 기록이 제거됩니다. 다른 캐릭터로 수정한 기존 참조는 이전 캐릭터 참조 목록에서도 제거됩니다.

## 평가의 의미

`수정이 다른 이미지에도 도움이 됐나요?`는 현재 참조 집합과 기준선을 고정하고 반례를 끈/켠 두 조건을 같은 남은 이미지에서 비교합니다. 직접 검토한 확정/보류 이미지와 참조·반례의 감지된 유사 원본은 양쪽 모두 제외합니다. 직접 고친 이미지를 제외해서 감소한 숫자를 학습 효과로 세지 않습니다.

예: 검증 세션에서 이미지 #67을 에이메스가 아닌 임시 캐릭터로 수정했을 때:

- 직접 수정한 이미지 제외, 동일한 남은 66장
- 에이메스 발견 14 → 14, 놓침 0 → 0
- 오탐 5 → 2

이는 이미 확인한 작은 자료의 탐색 결과입니다. 새로운 자료에 대한 독립 평가나 실제 캐릭터 전반의 정확도가 아닙니다. 반례마다 효과가 다르며 좋은 경우를 사용자 세션에 미리 적용하지 않았습니다. 전체 단일 반례 진단은 `review-diagnostic.json`에 있습니다.

다른 캐릭터 간 정확도는 이 자료에 정답이 없어서 평가할 수 없습니다. 정답 폴더 수정만으로 신경망을 재학습하지 않으며, 캐시된 특징과 명시적 참조·반례를 비교하는 규칙입니다. 단독 캐릭터 영역 검출이나 다인 이미지 판별은 추가하지 않았습니다.

## 저장과 경계

분류 폴더는 브라우저 상태 안의 가상 폴더입니다. 원본 파일/실제 폴더/라쿠믹스/서버 DB를 변경하지 않습니다. 모델 및 입력 내용으로 구분한 localStorage에 분류·참조·반례·되돌리기 기록을 저장합니다. 다른 브라우저로 자동 동기화하지 않습니다. 저장 실패는 화면에 알립니다.

`검토 기록 저장`으로 분류와 원본 해시, 모델 정보, 이력을 JSON으로 다운로드할 수 있습니다. JSON 복원 UI는 이번 범위에 없습니다. `실험 처음으로`도 되돌릴 수 있는 최신 작업으로 저장합니다.

브라우저 검증은 `?verify=1`의 분리된 저장 키를 사용했습니다. 일반 사용자 주소에는 검증용 캐릭터나 수정 결과를 남기지 않습니다.

## 검증

- `node --test review-engine.test.mjs`: 8개 통과, exit 0. 확정 보호, 명시적 참조 등록, 오수정 취소 시 모순된 반례/참조 제거, 보류 의미, 후보 충돌, 정답 라벨 미사용, 동일 평가 범위, LIFO 되돌리기.
- `node review-evaluate.mjs`: 실제 자료 진단, exit 0. 입력/사용자 브라우저 상태를 변경하지 않음.
- 브라우저: 새 폴더 생성 → 선택 1장 정답 수정 → 확정 1장/참조 0장 → 명시적 참조 1장 등록 → 등록만 되돌리기 → 새로고침 후 수정·반례 유지 확인.
- 브라우저: 에이메스 한 장 승인 후 참조는 5장 그대로, 확정은 6장으로 증가. 미확인 재계산 뒤에도 해당 이미지 #18이 확정에 남아 있음을 확인.

모델 재실행이나 Lakomics 빌드/네이티브 검증은 이 변경에 포함하지 않았습니다.
