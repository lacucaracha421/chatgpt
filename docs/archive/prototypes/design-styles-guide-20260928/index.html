스큐어모피즘 (Skeuomorphism)

2007–2013 · 초기 iPhone(iOS 6까지), 옛 macOS

화면 속 물건을 진짜 물건처럼 그리는 방식. 가죽 달력, 나무 책장, 금속 버튼, 광택 나는 버튼처럼 재질·그림자·빛 반사를 흉내 냅니다.

  • 장점: 처음 보는 사람도 "누르면 되겠다"를 바로 앎
  • 단점: 무겁고 낡아 보이기 쉬움, 화면이 장식으로 복잡
Lakomics: 앱 전체에는 안 맞음. 다만 만화책·게임 케이스의 물성 표현이 바로 이 계열이고, 소장품 감상 화면에서만 제한적으로 씁니다.

플랫 디자인 (Flat)

2010–2015 · Windows Phone "Metro", iOS 7, 초기 웹

스큐어모피즘의 반대. 그림자·질감을 전부 빼고 단색 면과 글자만 남깁니다. 강한 원색, 네모 타일.

  • 장점: 깔끔, 빠름, 어떤 화면 크기에도 잘 맞음
  • 단점: 무엇이 버튼인지 헷갈림, 밋밋함
Lakomics: "그림자는 떠 있는 것에만"이라는 우리 규칙의 뿌리. 다만 원색 대신 어두운 중성색을 씁니다.

머티리얼 디자인 (Material Design)

2014–현재 · Google, Android. 최신은 Material 3 ("Material You", 2021)

플랫에 "종이가 겹쳐 있다"는 규칙을 더한 체계. 높이(그림자)로 순서를 보여 주고, 움직임에 물리 규칙을 줍니다. Material 3는 크게 둥근 모서리, 알약 버튼, 배경화면에서 뽑은 파스텔 색이 특징.

  • 장점: 규칙이 매우 자세함(간격 8 격자, 누르는 영역 48, 글자 단계 등) — 우리가 참고한 숫자도 여기서 옴
  • 단점: 그대로 쓰면 "구글 앱"처럼 보임, 둥글고 귀여운 인상
Lakomics: 규칙(격자·크기)은 빌려 왔지만 모양(알약·큰 반경·파스텔)은 쓰지 않음. 입력창 "면 + 입력 중 밑줄"이 머티리얼의 Filled 입력창 계열.

Apple 스타일 (macOS · iOS)

macOS Big Sur(2020) 이후, iOS 7 이후 · Human Interface Guidelines

반투명한 창 뒤로 배경이 흐리게 비치는 "비브런시(Vibrancy)", 부드럽게 둥근 모서리, SF 폰트, 파란 강조색. 메뉴는 촘촘하고 단축키가 오른쪽에 흐리게 붙습니다.

  • 특징: 설명 글자를 거의 안 씀, 아이콘(SF Symbols)이 일관됨, 움직임이 짧고 부드러움
  • Mac vs iPad: 같은 회사지만 Mac은 글자 13, iPad는 17 — 우리가 PC 15 / 태블릿 17로 나눈 근거
  • 단점: 반투명은 느린 PC에서 무겁고, 따라 하면 "가짜 맥"처럼 보임
Lakomics: 크기 규칙, 누르는 영역 44, 토글 스위치 모양, "글자는 최소로"를 빌려 옴. 반투명·파란 강조는 쓰지 않음.

Windows Fluent Design

2017–현재 · Windows 10/11, Microsoft Office

Windows 11의 모습. 배경화면 색이 은은하게 비치는 "미카(Mica)" 창, 8px 둥근 모서리, 아래쪽 버튼 영역이 살짝 다른 면, 하늘색 강조. Segoe UI Variable 폰트.

  • 장점: Windows에서 쓰면 "원래 있던 앱"처럼 자연스러움
  • 단점: Linux·Android에서는 어색, 회사 느낌이 강함
Lakomics: Windows·Linux·태블릿 모두에서 같아야 해서 어느 OS 스타일도 그대로 따르지 않음. 대화상자 아래 버튼 영역을 나누는 방식 정도는 참고할 만함.

글래스모피즘 (Glassmorphism)

뉴모피즘 (Neumorphism)

2019–2021 · Dribbble(디자이너 작품 공유 사이트)에서 유행

배경과 같은 색의 버튼이 밝은 그림자·어두운 그림자로 튀어나오거나 파인 것처럼 보이는 방식. 말랑한 플라스틱 느낌.

  • 장점: 부드럽고 촉감 있어 보임
  • 단점: 대비가 너무 낮아 버튼이 안 보임, 실제 앱에선 거의 실패 — 지금은 "한때 유행"
Lakomics: 쓰지 않음. 어두운 화면에서는 특히 안 보임.

스위스 스타일 (International Typographic Style)

1950년대 스위스 포스터 → 지금도 편집·브랜드 디자인의 기본

장식 없이 격자, 큰 글자, 여백, 강한 대비만으로 질서를 만드는 방식. 숫자·제목을 아주 크게, 나머지는 작게. 빨강 같은 포인트 색 하나.

  • 장점: 오래 봐도 질리지 않음, 정보가 또렷
  • 단점: 잘못 하면 딱딱하고 차가움
Lakomics: 가장 가까운 뿌리 중 하나. "글자 크기 4단계", "간격 사다리", "큰 숫자는 Rajdhani"가 이 생각에서 나옴.

네오 브루탈리즘 (Neo-brutalism)

2021–현재 · Gumroad, 일부 스타트업 웹

일부러 투박하게. 두꺼운 검은 테두리, 딱딱한 검은 그림자, 형광 원색, 굵은 글자. "예쁘게 다듬지 않았다"는 개성.

  • 장점: 한눈에 기억에 남음, 재미있음
  • 단점: 시끄러워서 오래 쓰는 도구에는 피곤함
Lakomics: 안 맞음. 다만 "딱딱한 그림자(흐림 없는 그림자)"는 우리 NieR 선택 표식의 그림자 테두리와 같은 기법.

"AI 느낌" — 요즘 SaaS 스타일

2022–현재 · AI 서비스, 스타트업 랜딩 페이지, AI가 만든 화면에서 특히 자주 보임

사용자가 "AI 같아서 싫다"고 한 바로 그 계열. 어두운 바탕에 보라·분홍 그라데이션, 빛 번짐(glow), 알약 배지, 카드 왼쪽 색 띠, 그라데이션 글자. Linear·Vercel 같은 잘 만든 원조가 있는데, 그 겉모습만 복사한 화면이 너무 많아져서 "흔한 AI 디자인"의 상징이 됨.

  • 왜 AI처럼 보이나: 누구나 같은 재료(보라 그라데이션, 글로우, 색 띠, 둥근 카드)를 조합해서 개성이 없음
  • 알아보는 법: 강조색이 보라/분홍, 빛 번짐, 제목에 그라데이션, "✨", 모든 게 둥근 카드
Lakomics: 피해야 할 목록. DESIGN.md에 "색 띠 금지", "장식용 그라데이션·글로우 금지"로 적혀 있음.

게임 UI — NieR:Automata

2017 · 게임 메뉴 디자인의 대표 사례 (비슷한 계열: Persona 5는 반대로 화려한 쪽)

4 · 알아 두면 좋은 용어

계층 (Hierarchy)무엇을 먼저 보게 할지의 순서. 크기·굵기·색·위치로 만듦.
어포던스 (Affordance)"이건 누를 수 있겠다"는 느낌. 스큐어모피즘은 강하고 플랫은 약함.
대비 (Contrast)글자와 바탕의 밝기 차이. 너무 낮으면 안 읽힘(뉴모피즘의 실패 원인).
밀도 (Density)한 화면에 담는 정보량. PC 관리 도구는 높게, 태블릿 감상은 낮게.
높이 · 엘리베이션 (Elevation)화면 위에 "떠 있는 정도". 그림자로 표현. 메뉴 < 대화상자 순으로 높음.
반경 (Radius)모서리 둥근 정도. 작으면 단정·전문적, 크면 친근·귀여움.
토큰 (Design token)색·간격·크기에 붙인 이름. 예: "보조 글자 = 12px". 한 곳만 바꾸면 전체가 바뀜.
디자인 시스템토큰 + 부품 + 규칙 묶음. Material, Apple HIG, Fluent가 대표. 오늘 만든 DESIGN.md 12장이 Lakomics의 것.
컴포넌트 (Component)재사용하는 부품. 버튼, 입력창, 배지 등.
스켈레톤 (Skeleton)불러오는 동안 나올 자리를 회색 모양으로 미리 보여 주는 것.
토스트 (Toast)화면 아래에 잠깐 떴다 사라지는 알림.
시트 · 모달 · 팝오버시트 = 아래에서 올라오는 판, 모달(대화상자) = 가운데 창 + 뒤를 어둡게, 팝오버 = 버튼 옆 작은 창.
비브런시 · 미카 · 아크릴Apple·Windows의 반투명 창 재질 이름.
이징 (Easing)움직임의 속도 곡선. 처음 빠르고 끝이 느린 곡선이 자연스러움.
히어로 (Hero)화면 위쪽의 크고 대표적인 이미지 영역.
그리드 (Grid)줄을 맞추기 위한 보이지 않는 칸. 간격 사다리(4·8·12…)와 함께 씀.
