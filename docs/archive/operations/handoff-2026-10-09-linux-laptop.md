## 4. 옮겨 둘 작업 메모 (Claude용)

- **서버 비밀값 출력 금지:** 서버 설정 파일(`/etc/systemd/system/lakomics-api.service.d/*.conf`, `.env`)은 "가려서"라도 내용을 출력하지 않습니다. 키 이름과 길이, 모양만 확인합니다.
  - 2026-10-08에 가리기 규칙이 따옴표 형식을 놓쳐서 TMDB·IGDB 키가 대화에 찍힌 일이 있었습니다. 사용자는 교체하지 않기로 했습니다.
- **Codex 작업 뒤 남은 프로세스 정리:** `codex exec`가 끝난 뒤에도 `codex-linux-sandbox` 하위 프로세스가 몇 시간씩 남는 일이 있었습니다(멈춘 heredoc, 멈춘 테스트). 작업이 끝나면 `ps`로 확인하고 정리합니다.
- **디자인 서브에이전트는 high로 자동 실행:** 사용자가 effort를 매번 바꾸지 않아도 되게 합니다.
- **노트북 전용:** 노트북의 기본 Codex 계정은 Sol을 쓸 수 없어서 `CODEX_HOME=~/.codex-b`를 씁니다. Windows PC에는 해당되지 않습니다.
