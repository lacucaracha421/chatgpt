# Domain Docs

엔지니어링 스킬이 저장소의 도메인 문서를 읽는 방법을 정의합니다.

## 코드 탐색 전에 확인할 문서

- 저장소 루트의 `CONTEXT.md`
- 저장소 루트에 `CONTEXT-MAP.md`가 있다면 관련 컨텍스트의 `CONTEXT.md`
- 작업 영역과 관련된 `docs/adr/` 문서

파일이 아직 없다면 별도로 문제 삼지 않고 계속 진행합니다. 도메인 용어나 아키텍처 결정이 실제로 정리될 때 관련 스킬이 문서를 생성합니다.

## 파일 구조

이 저장소는 단일 컨텍스트 구조를 사용합니다.

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## 도메인 용어

이슈 제목, 리팩터링 제안, 가설, 테스트 이름에는 `CONTEXT.md`에 정의된 용어를 사용합니다.

## ADR 충돌

작업 내용이 기존 ADR과 충돌하면 조용히 덮어쓰지 말고 충돌 사실을 명시합니다.
