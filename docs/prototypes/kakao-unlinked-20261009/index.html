컬렉션 · 만화 — Kakao 미연결 작품 한 번에 연결하기

만화 150개 중 122개가 Kakao 미연결, 연결된 28개 중 10개는 일부 권만 연결돼 있습니다. 두 안 모두 같은 원칙을 따릅니다: 클릭 한 번이면 그 작품의 기존 Kakao 연결 창이 검색을 마친 상태로 열리고(검색어는 작품명, 작품명이 한국어가 아니면 MangaDex의 한국어 제목), 연결하면 그 작품이 번쩍임 없이 목록에서 접혀 빠집니다. 창에서 바로 연결 안 함을 고를 수 있어 목록이 0까지 줄어듭니다. 실제 앱의 tokens / controls / Kakao 창 CSS를 그대로 불러온 시안이며, PC 1440×900과 태블릿 800×1280(75 % 축소)을 함께 보입니다.

A안 · 연결 점검 화면 만화 바로가기 줄에 “연결 점검 122” — 신간처럼 목록 자리에 열리는 할 일 목록

A-1 · 들어가는 곳과 미연결 목록 PC · 직접 눌러 보세요: 찾기 → 연결

만화 섹션 바의 바로가기 줄(쇼케이스 · 신간 다음)에 연결 점검과 남은 개수가 붙습니다. 0이 되면 바로가기 자체가 사라집니다. 누르면 신간 화면처럼 목록 자리를 바꾸고 제목줄은 ‹ Kakao 연결 점검. 맨 위 세그먼트로 미연결 · 일부 권 · 제외를 오갑니다. 줄마다 쓸 검색어가 입력칸에 이미 들어 있고 오른쪽에 그 출처(작품명 / MangaDex 한국어 제목 / 한국어 제목 없음)가 흐리게 보입니다. 고칠 수 있고, Enter나 찾기가 Kakao 창을 엽니다. 연결 안 함은 줄에 올리거나 포커스가 왔을 때만 보입니다. ↑↓로 줄 이동, Enter로 찾기.

A-2 · 찾기를 누른 직후의 Kakao 창 PC · 기존 KakaoConnectDialog 그대로, 검색을 마친 상태로 열림

창은 지금 쓰는 Kakao 연결 창(검색 · 결과 · 권 미리보기)을 그대로 씁니다. 바뀌는 점은 네 가지: ① 맨 위에 어떤 작품인지(표지 · 이름 · 보유 권) ② 열자마자 검색이 끝나 있음 — 0.3초 안에 끝나면 아무 표시 없이 결과가 나오고, 늦어지면 결과 자리 스켈레톤, 0.4초가 지나야 “검색 중…” ③ 결과 제목이 검색어와 같은 묶음 하나는 미리 골라 둠 → 연결 한 번 ④ 왼쪽 아래 연결 안 함(이 작품은 Kakao에 국내판이 없음). 기존 창의 설명 문장 두 줄은 뺐습니다.

A-3 · 일부 권 PC · 연결된 28개 중 10개

권마다 작은 사각형 하나 — 채워진 칸은 Kakao에 있는 권, 빈 칸은 빠진 권. 옆에 빠진 범위를 글로. 다시 연결은 같은 창을 지금 연결된 검색어로 열고, 이미 연결된 묶음은 체크된 채, 같은 시리즈로 보이는 다른 묶음(완결판 · 출판사 변경 등)을 위에 올려 둡니다. 이대로 두기는 빠진 권을 받아들이고 제외로 보냅니다. 기준 권 수(사각형 개수)가 무엇인지는 열린 질문입니다.

A-T · 태블릿 800×1280 세로 · 75 % 축소 · 바로가기 → 아래에서 올라오는 오버레이 → 검색 시트

태블릿은 바로가기 오버레이(위 36px만 남김)로 같은 목록을 엽니다. 줄 높이 64, 줄 전체가 탭 대상(시트 열기), 끝의 ⋯(44)에 연결 안 함. 검색어는 둘째 줄에 — 작품명과 다를 때만 “검색어 …”와 출처를 적습니다. 태블릿 연결은 PC가 적용하는 요청이라, 요청한 작품은 목록에서 빠져 맨 아래 PC 적용 대기 접힘으로 갑니다.

줄을 탭하면 기존 BindSearchSheet가 검색을 마친 채 올라옵니다. 검색어는 시트의 입력칸에서 고칩니다. 점검 목록에서 열었을 때는 연결 요청 한 번으로 끝나고(지금의 “이 작품으로 연결할까요?” 확인 단계를 건너뜀 — 열린 질문), 왼쪽 아래 연결 안 함.

B안 · 만화 목록의 Kakao 필터 정렬 · 내 별점 옆 “Kakao ⌄” — 평소 표지 목록을 걸러서 표지를 누르면 바로 Kakao 창

B-1 · 필터를 켠 만화 목록 PC · 직접 눌러 보세요: 표지 → 연결

보기 컨트롤에 Kakao 메뉴가 생깁니다(전체 / 미연결 122 / 일부 권 10 / 제외). 고르면 평소 격자·선반·책장이 그대로 걸러지고, 목록 머리는 Kakao 미연결 122 + 필터 초기화. 이 필터가 켜진 동안에만 표지 클릭이 작품 대신 Kakao 창을 열고, 올리면 표지 아래에 “찾기” 배지가 뜹니다. 검색어가 작품명과 다를 때만 제목 밑에 흐리게 적힙니다(편집은 창의 입력칸). 작품 열기는 우클릭 메뉴와 창의 표지. 연결하면 표지에 체크가 잠깐 덮였다가 흐려지며 빠지고 옆 표지들이 미끄러져 자리를 메웁니다.

B-2 · 일부 권 필터 PC · 표지 위 권 수 배지

일부 권은 표지 위 scrim 배지 8/13권으로만 보입니다. 표지를 누르면 A-3과 같은 다시 연결 창. 빠진 권 범위는 창 안에서 보입니다.

공통 두 안 모두 같은 규칙

연결 후 — 번쩍임 없이 빠지기

창은 140 ms에 닫히고 줄은 창이 닫힌 뒤에 바뀝니다. 성공 토스트는 없고(디자인 §12: 성공은 그 자리에서), 연결 안 함만 되돌리기 토스트가 뜹니다. 연결이 실패하면 창이 닫히지 않고 한 줄 오류 + 다시 시도. 동작 줄이기 설정이면 접힘 없이 바로 빠집니다. 개수(122 → 121)는 접히기 시작할 때 한 번 바뀝니다.

기본 검색어 규칙

  • 작품명에 한글이 있으면 작품명 — 원피스, 귀멸의 칼날, 스파이X패밀리. 출처 “작품명”.
  • 한글이 없으면 MangaDex 연결의 한국어 대체 제목(ko 태그 첫 번째) — Uma Musume: Cinderella Gray → 우마무스메 신데렐라 그레이. 출처 “MangaDex 한국어 제목”.
  • 둘 다 없으면 작품명 그대로, 출처 “한국어 제목 없음” — 결과가 비면 창에 “검색 결과 없음”과 연결 안 함이 바로 보입니다.
  • 사용자가 고친 검색어는 그 작품에 기억되고(목록을 닫았다 열어도 유지), 연결에 성공하면 그 검색어가 지금처럼 바인딩의 query로 저장됩니다.

연결 안 함

  • 새 상태를 만들지 않고 이미 있는 “카카오 연결 안내 숨기기”(작품 편집 · 권 범위 칸의 체크, hideConnectionPrompt)를 켭니다. 작품 화면의 연결 안내가 접히는 것과 같은 뜻이라 PC·태블릿·서버가 이미 같은 값을 나눠 씁니다.
  • 제외 탭에서 다시 점검으로 되돌립니다. 일부 권의 “이대로 두기”는 이 값으로 표현이 안 돼 새 표시가 필요합니다(열린 질문).
