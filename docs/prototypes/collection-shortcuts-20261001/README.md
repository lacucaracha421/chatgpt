# Collection shortcuts row (2026-10-01)

Accepted 2026-10-01 for the tablet. The 컬렉션 section bar gets a second row in the same segmented track:
the type's shortcuts (쇼케이스 with its work count; 발매 캘린더 with its new-event count, accent-coloured,
hidden at zero). The second row is a set of shortcuts, never a selection: no accent fill.

- Tapping a shortcut opens it as an overlay rising from the bottom over the list (top ~36px of the screen
  stays visible, dimmed). Swipe down, tap outside, ✕ or Back closes it; the list underneath keeps its place.
  A work opened from the overlay stacks above it; Back returns to the overlay.
- The fold rows above the list ("쇼케이스 12 ›", "발매 캘린더 9 ›") are removed.
- The pulled-down shade carries both rows.
- PC is unchanged: its sidebar index already holds 쇼케이스 and 발매 캘린더.
