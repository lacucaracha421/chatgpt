View Transitions 시연

브라우저가 바뀌기 직전 화면을 그림으로 찍어 두고 새 화면과 교차시키는 방식입니다. 이전 화면이 다시 배치되거나 흔들릴 수 없습니다. 왼쪽 레일의 탭, 폴더 카드, 썸네일을 눌러 보세요.

  • 탭 전환: 사이드바가 있는 탭(에셋) ↔ 없는 탭(홈·컬렉션). 사이드바와 본문이 각자 그림으로 찍혀 0.15초 교차합니다. 이전 화면은 찍힌 그림이라 폭이 바뀌어도 흔들리지 않습니다.
  • 폴더 들어가기: 누른 폴더의 표지가 그대로 날아가 위쪽 제목 옆 작은 표지가 되고, 본문은 오른쪽에서 들어옵니다. 경로(에셋 ›)를 누르면 반대로 돌아갑니다.
  • 썸네일 열기: 썸네일이 그 자리에서 커지며 뷰어가 되고, 닫으면 원래 칸으로 돌아갑니다.
