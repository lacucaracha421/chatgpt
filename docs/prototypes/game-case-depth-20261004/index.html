제안: 고정 칸

두께뚜껑과 받침이 각각 케이스 두께의 절반(실물 약 5.5 mm)인 얕은 상자예요. 닫으면 둘이 맞물려 가운데에 이음선이 생겨요.
안쪽 벽테두리 벽에 안쪽 면과 윗면(립)을 따로 그려서, 펼쳐도 받침의 깊이와 카드 홈이 보여요.
내부 디테일받침 바닥에 둘레 테, 리브, "GAME CARD" 양각, 움푹한 카드 홈(위아래 고정 돌기, 손가락 홈)을 넣었어요. 뚜껑 안쪽에는 테두리 단차와 종이를 누르는 클립 두 개, 책등 안쪽에는 접히는 홈 두 줄이 있어요. 플라스틱에 아주 옅은 결도 넣었어요.
책등펼치면 책등이 두 받침의 바닥과 같은 높이에 평평하게 놓여요. 뚜껑을 4° 들어 올리던 각도도 없애서 틈이 사라져요.
