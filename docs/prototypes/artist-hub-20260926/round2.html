작가 허브 목업 2차 — ARTIST-001

1차에서 고른 A(작가 색인 → 작가 페이지)에 B의 “오늘” 줄을 얹고, 실제 라이브러리 규모(작가 2,344명 중 한 장뿐인 작가 1,796명, 작가·출처가 모두 없는 이미지 4,742장)에 맞춰 많은 작가를 편하게 관리하는 화면을 그렸습니다. 새로 들어간 것: 자동 구분(주요 작가 / 그 외 / 한 장뿐인 작가), 고정·숨기기, 초성·핸들·이름 검색, 직접 지은 작가 이름과 원래 이름 목록, 합치기 제안, 작가 미상 이미지에 작가를 한꺼번에 붙이기, 출처 주소에서 작가 채우기. 태블릿 800 × 1280, PC 1680 × 1050. PC에서 선택된 줄은 아이보리 슬랩 + 오른쪽 작은 어두운 표식만 쓰고 왼쪽 바깥의 아이보리 사각형은 없습니다. 작가 이름·핸들·이미지는 모두 가상이며, 개수는 9월 26일 조사 숫자를 바탕으로 맞췄습니다(최근 30일 기준으로 더해지는 작가 수 등 일부는 예시).

1작가 색인 — 오늘 · 고정 · 주요 작가 · 나머지는 접기

맨 위는 1차 B안의 오늘 세 줄(이유 한 줄 + 이미지 줄, 넘기기)입니다. 그 아래 고정한 작가, 그리고 자동으로 고른 주요 작가가 이어집니다. 기준은 “5장 이상 또는 최근 30일 안에 2장 이상”이며 제목 옆에 작게만 적고, 누르면 숫자를 바꿀 수 있습니다(PC 그림의 작은 창). 나머지 작가는 그 외 작가 2,245명 한 줄로 접혀 있다가, 열면 이름만 촘촘히 보이는 검색 목록이 됩니다. 검색은 이름·핸들·초성(예: ㅅㄹ → 서리, 새롬, 수련…)을 모두 받고, 직접 지은 이름과 원래 이름 어느 쪽으로도 찾아집니다. 한 장뿐인 작가 1,796명은 이름 목록 대신 그림 모자이크로 훑어보는 입구를 따로 두었고, 작가가 없는 이미지는 작가 미상 4,742장 입구로 모았습니다. 숨긴 작가는 목록·오늘·검색에서 빠지고 숨긴 작가 필터에서만 보입니다.

2작가 페이지 — 직접 지은 이름 · 원래 이름 · 합치기

작가 이름은 내가 정한 표시 이름이 먼저 보이고, 수집할 때 들어온 이름과 핸들은 그 아래 원래 이름으로 남습니다(검색에는 모두 쓰임). 편집 시트에서 표시 이름을 바꾸고, 합쳐진 원래 이름을 하나씩 떼어내고, 다른 작가를 찾아 합치고, 고정·숨기기를 켜고 끕니다. 표시 이름을 비우면 원래 이름으로 돌아갑니다. 작가 미상에서 직접 붙인 이미지도 “직접 지정 N장”으로 같은 목록에 보여서 나중에 떼어낼 수 있습니다. PC는 같은 내용을 오른쪽 패널로 엽니다(본문 폭·스크롤은 그대로).

3같은 작가일 수 있어요 — 합치기 제안

앱이 먼저 후보를 찾아 한 쌍씩 보여 줍니다. 이유는 한 줄로: X 핸들이 같음(대소문자만 다르거나 표시 이름이 바뀐 경우), 이름이 같음(x.com과 pixiv처럼 사이트가 다름), 확실하지 않음(비슷한 핸들, 게시판 출처). 양쪽 이미지를 나란히 보고 합치기 또는 따로 두기를 누릅니다. 합칠 때 표시 이름을 고르거나 새로 적을 수 있고, 따로 두기를 누른 쌍은 다시 제안하지 않습니다. arca.live·dcinside처럼 올린 사람이 작가가 아닐 수 있는 출처는 경고 표시를 붙입니다. 제안은 색인의 정리 줄과 PC 인덱스 “정리”에서 들어옵니다.

4작가 미상 정리 — 한꺼번에 작가 지정 · 출처에서 채우기

작가 미상은 가져온 날짜 묶음으로 보여서 “이 묶음 모두 선택”으로 여러 장을 빠르게 고를 수 있습니다. 고른 뒤 작가 지정을 누르면 시트에서 기존 작가를 찾거나(직접 지은 이름 포함) 입력한 이름으로 새 작가를 만듭니다. 원래 파일·출처 정보는 바꾸지 않고 “이 이미지는 이 작가”라는 연결만 더합니다. 출처에서 작가 채우기는 출처 주소는 있는데 작가가 비어 있는 699장을 사이트별로 미리 셉니다. x.com은 주소에 핸들이 있어 바로 채우고, pixiv는 작품 번호로 작가를 조회해야 해서(온라인) 따로 버튼을 두었습니다. arca.live·dcinside는 글쓴이가 작가가 아닌 경우가 많아 자동으로 채우지 않고 게시글별로 모아 작가 지정 시트로 넘깁니다.
