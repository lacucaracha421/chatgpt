# 컬렉션 도구 줄 — 보기 하나로 합치기 (2026-10-13)

사용자 의견 4번: PC 컬렉션 섹션 바의 정렬 · 내 별점 · 보기를 하나로 합치고, 상단 바 ⋯ 안의 책등 받기도 그 안에 넣는다. 시안: `index.html` (앱의 실제 `tokens.css`, `controls.css`, `chrome.css`, `assets.css`, `CollectionBrowser.css`를 불러옴).

이 영역은 2026-10-02 바로가기 한 줄 결정(섹션 바 B안)으로 이미 손본 곳이다. 이번 안은 그 줄의 오른쪽 절반만 다시 정리한다.

## 지금 있는 컨트롤

- 상단 바: 제목(섹션 바 내려받기), 작품 수, "검색" 글자 버튼(팝오버), ⋯ 작품 관리(게임만, 안에 책등 받기 하나), 실행 중 책등 진행, 검색어 배지, + 새 컬렉션.
- 섹션 바: 유형 게임/만화/영화/AV | 쇼케이스, 발매 캘린더 N 또는 신간 N, 연결 점검 N(만화, 있을 때만) | 정렬 메뉴, 내 별점 메뉴, 보기.
- 목록 시작: '전체 184'(검색·필터 중엔 '검색 결과'), AV는 품번 받은함.

## 추천: 제안 A

- 섹션 바 오른쪽: **쇼케이스 · 발매 캘린더(또는 신간 · 연결 점검) | 보기**. 바로가기는 지금처럼 한 번에 닿는다.
- 공용 `ViewOptionsMenu`(에셋 보기와 같은 메뉴) 하나에 순서대로 담는다. 순서는 에셋 보기 규칙(2026-10-05)을 따른다: **내 별점 → 배치 → 정렬 → 관리**.
  - 내 별점: 지금 슬라이더와 미평가를 그대로 쓴다. 초기화는 필터가 켜졌을 때만 섹션 이름 끝에 보인다.
  - 배치: 격자/선반(만화는 책장까지)과 한 줄에 N개. 지금과 같다.
  - 정렬: 기준 [발매일 | 추가일 | 제목]과 순서 [최신순 | 오래된순](제목이면 [가나다순 | 역순]). 게임만 위에 묶기 [안 묶음 | 기기 | 발매 연도]가 붙는다. 태블릿 시트의 기준/순서 나눔과 같다.
  - 관리(게임, PC만): 책등 받기. 실행 중에는 진행과 취소가 이 자리에 나오고, 상단 바 진행 표시도 지금처럼 남는다.
- 켜진 내 별점은 목록 첫 줄에 회색 칩 "★ 내 별점 4.0 ✕"로 보인다. ✕로 바로 빠진다.
- 상단 바에는 **제목 · 수 … 돋보기 · +**만 남는다. ⋯ 작품 관리 버튼은 없어진다.

제안 B는 쇼케이스까지 보기 맨 위 '범위 [전체 | 쇼케이스]'로 넣는다. 섹션 바는 가장 조용해지지만, 쇼케이스가 두 번 클릭이 된다. 2026-10-02의 버튼 결정도 되돌리게 되므로 추천하지 않는다.

## 태블릿

- 0.9.73 규칙은 그대로 둔다: 상단 바는 제목 · 찾기 · ⋯, 섹션 바는 유형 | 쇼케이스 · 발매 캘린더/신간 | 보기 · +. 태블릿은 이미 보기 시트 하나로 합쳐져 있다.
- 시트 안 순서를 PC와 같은 **내 별점 → 배치 → 정렬**로 바꾼다(지금은 정렬 → 내 별점 → 배치). 정렬은 같은 세 줄을 44px 분할 컨트롤로 보인다.
- 보기 섹션을 공용 조각 하나로 만들어 PC는 메뉴에, 태블릿은 `BottomSheet`에 담는다(DESIGN §12). 따로 있는 두 별점 슬라이더(PC `RatingFilter`, 태블릿 `RatingFilterSlider`)도 이때 하나로 합친다. 책등 받기는 PC 라이브러리 명령이라 태블릿에는 관리 섹션이 없다.

## 정할 것

1. 쇼케이스 자리: A 섹션 바 버튼 그대로(추천) / B 보기 → 범위.
2. 보기 안 순서: 내 별점 → 배치 → 정렬 → 관리(추천, 태블릿도 따라 바뀜) / 태블릿처럼 정렬 먼저.
3. 켜진 내 별점 표시: 목록 첫 줄 칩 + ✕(추천) / 보기 안에서만.
4. 검색 버튼: 돋보기 아이콘만 남기고 지금 팝오버 그대로(추천) / 찾기(Ctrl+Q)의 "이 화면에서" 줄로 통일하고 버튼 제거(태블릿 방식).
