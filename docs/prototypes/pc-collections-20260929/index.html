PC 컬렉션 — 리디자인 시안 (2026-09-29)

현재 화면(스크린샷 2026-09-29 18:54–18:55)의 문제: 정렬·내 별점이 사이드바에, 상단바에 개수 없음, 쇼케이스는 가는 스크롤 줄, 작품 상세에서 제목이 세 번(상단바·사이드바·히어로), 작품 정보가 사이드바(색인 자리)에 들어감, "작품 관리" 링크가 떠 있음, 신간 알림 체크박스, AV 상세·배우 페이지만 완전히 다른 구성, 태그 칩 테두리+면, 아트워크 변경 창의 떠 있는 선택 점, 신간 목록의 로캘 날짜. 에셋·망가 시안의 결정(상단바 조작, 공통 선반, 오버레이, 섹션 제목)을 이어받음. ?frame=a|b|c|d|e.

A목록

  • 상단바: 게임 181 · 정렬 · 내 별점(전체 · ★3+ · 미평가) — 사이드바에서 올림. 사이드바는 유형과 소식(신간 개수)만.
  • 쇼케이스는 공통 선반(휠·끌기·화살표), 제목 옆 개수와 › 전체 보기. 카드: 케이스 표지 + 제목 1줄 + 제작사 · 연도 · ★ 한 줄.

B작품 상세 — 하나의 틀 (게임)

  • 히어로 배경 위에 표지 · 제목(한 번만) · 원제 · 연도 · 별점 · 동작(쇼케이스, 편집 ⋯). 오른쪽 열에 정보(개발사, 배급사, 플랫폼, 장르), 태그는 면만 있는 칩.
  • 아래로 섹션: 개요 → 스크린샷·아트워크(선반) → 관리는 ⋯ 메뉴로. 사이드바는 컬렉션 색인 그대로(작품 정보를 넣지 않음).

C작품 상세 — 만화 (같은 틀)

  • 오른쪽 열에 소장 카드: 판(기본판 · 대체판) 전환, 보유 권수 스테퍼, 신간 알림 토글, 최신 5권 · 미보유 1. 저장 버튼 없이 바로 반영.
  • 권별 표지 격자: 보유는 선명, 미보유는 흐리게 + 점선.

C1만화 — 소장을 정보 열에 이어서

  • 카드 없이 오른쪽 정보 열 아래에 같은 글자·줄 간격으로 판 · 보유 · 신간 알림.

C2만화 — 소장을 제목 아래 한 줄로

  • 동작 버튼 아래 한 줄: 보유 − 4 + / 5권 │ 신간 알림 │ 판 선택 메뉴.

D작품 상세 — AV (같은 틀)

  • AV도 같은 구성: 표지(앞면 · 책등 · 뒷면 전환은 표지 아래), 품번 · 제목 · 발매 · 별점, 오른쪽 열에 메이커 · 레이블 · 태그, 아래 섹션에 출연(배우 → 배우 페이지)과 감독.
