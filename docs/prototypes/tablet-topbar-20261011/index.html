태블릿 상단바 정리 시안 · 2차

화면마다 제각각이던 상단바 버튼을 PC와 같은 자리 나눔으로 맞춘다. 시안은 Galaxy Tab S11 크기(세로 674px, 가로 1078px)이고, 앱의 실제 tokens.css · controls.css · Pretendard를 쓴다. 칸 너비는 화면에 그려진 그대로 재서 각 틀 아래 "측정"에 적었다.

2차에서 바뀐 것 — "PC에 맞춰 작게 표시하면 태블릿에선 불편하다"는 의견 반영. 기준은 지금 컬렉션 화면의 게임/만화/영화/AV 칸(약 93 × 44px, 사용자가 괜찮다고 한 크기).
  • 분류 칸은 줄이지 않는다 — 1차의 글자 폭 분류(전체/이미지/영상 각 약 60–80px)를 버리고, 분류가 도구를 뺀 나머지 폭을 모두 쓴다. 가장 좁은 컬렉션도 칸이 지금보다 넓다(93 → 112px).
  • 그 대신 태블릿 분류 막대 도구는 바로가기 | 보기 · + 로 줄인다. 정렬 · 내 별점은 보기 시트 안으로(PC 에셋 "보기"가 이미 정렬을 품는 것과 같은 방식).
  • 하단 바는 지금 다섯 칸 그대로(칸 약 128px). 1차 안 1의 7칸(약 88px)은 기준보다 좁아져서 내린다. 찾기 · 더보기는 모든 화면 상단바 끝 [][⋯](1차의 안 2)으로.
