6. 태블릿

  • 작업 칸: 이 목록의 일은 모두 PC에서만 돈다. 태블릿에는 상태 패널이 없고 서버를 읽기만 하므로 이번 라운드에 태블릿 화면은 바뀌지 않는다. 행 부품(아이콘 · 이름 · 숫자 · 막대 · 정지)은 공용 조각으로 만들어 두어, 나중에 태블릿이 서버 쪽 일(캡처 처리, 신간 확인 등)을 보여 줄 때 그대로 쓴다.
  • 할 일: 태블릿 메모도 같은 `MemoEditor`를 쓰므로 같은 라운드에 같이 바뀐다. 차이는 크기뿐: 세 아이콘은 44 터치 영역(보이는 아이콘 24), B안을 골라도 태블릿에서는 늘 보임, 섹션이 없는 메모의 "섹션 추가" 줄은 높이 44.

7. 정할 것

  1. 작업 칸 A안(상태별 한 목록) / B안(담당별 묶음) — 추천 A.
  2. 머리 버튼 숫자: 지금처럼 직접 시작한 일만 셀까(추천), 배경 일까지 셀까. 배경까지 세면 거의 늘 "작업 N"이 떠 있게 된다.
  3. 최근 끝남을 둘까(추천: 이 실행 동안 1시간 · 10개, 기본 접힘), 아예 뺄까.
  4. 동기화 칸의 "동기화 중 · N개 남음"을 작업 칸으로 옮기기 — 추천 옮김.
  5. 할 일 A안(늘 보임) / B안(머리에 포인터가 있을 때만) — 추천 A.
  6. ＋의 위치: 누른 섹션 바로 아래(추천) / 늘 맨 끝(지금 동작).
