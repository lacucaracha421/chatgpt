반원 저장 메뉴 · 더 단순하게

Lakomics Companion 확장에서 이미지를 길게 누르면 열리는 반원 메뉴입니다. 지금은 가운데 반원 한 버튼에 저장·뒤로·임시저장이 숨어 있고 겉으로는 구분이 안 보입니다.

새안은 차분한 반투명 회색 부채꼴에 강조색은 아이보리 하나(가운데 저장 원과 고른 폴더)만 씁니다. 가운데는 할 일 하나만 보여 줍니다: 맨 위에서 아직 폴더를 안 골랐으면 임시저장, 폴더를 고르면 여기 저장 · 폴더 이름. 아래로 밀기도 하나뿐입니다: 맨 위에서는 임시저장, 폴더 안에서는 뒤로. 그래서 임시저장 버튼은 따로 없고, 위로 밀기도 없습니다. 번역은 저장에서 먼 바깥 모서리의 작은 원 하나입니다.

모든 화면은 실제 크기(px)입니다. 이미지는 모두 그려 낸 견본입니다. 페이지는 마우스 휠로 그대로 내려갑니다.

B · 세 가지 안 눌러 보기

안 기기 열린 쪽

① 아래 줄 — 부채꼴 아래 화면 가장자리에 붙은 얇은 반투명 줄 하나에 번역과 (폴더 안에서만) 뒤로가 아이콘+작은 글씨로 들어갑니다. 할 일이 한곳에 모여 찾기 쉽지만, 메뉴가 세로로 조금 길어집니다.

② 위성 — 폴더 안에서만 가운데 원 위쪽 테두리에 작은 ⌃ 뒤로 탭이 붙고, 번역은 바깥 모서리의 작은 원입니다. 메뉴가 가장 작지만 뒤로 탭이 작습니다(누르는 범위 40×44px).

③ 경로형 (추천) — 폴더 안에서만 부채꼴 위에 ‹ 상위 폴더 이름 버튼이 뜹니다. "지금 어디인지"를 보는 자리에서 바로 위로 가니 따로 배울 것이 없습니다. 번역은 바깥 모서리의 작은 원 하나. 보이는 부품이 가장 적습니다.

폴더를 한 번 누르면 고르기, 두 번 누르면 하위 폴더 열기(하위가 없으면 바로 저장). 가운데를 아래로 48px 이상 밀었다 놓으면 맨 위에서는 임시저장, 폴더 안에서는 뒤로. 메뉴 바깥을 누르면 닫히고, 닫힌 뒤 이미지를 누르면 다시 열립니다(실제로는 길게 누르기).
