PC 에셋 — Eagle에서 배운 네 가지

지금 에셋 화면에 네 가지만 더한 시안입니다. 색과 모양은 지금 앱의 실제 스타일 파일을 그대로 씁니다. 점선 테두리는 새로 생기는 부분 표시이고 실제 화면에는 없습니다. 그림을 눌러 바꾸고, 칩의 ×와 +, 크기 막대, 왼쪽 「정리할 것」을 직접 눌러 보세요.

  1. 1정보 패널 고정: 패널 머리의 핀을 누르면 패널이 목록 옆에 붙고 그림들이 그만큼 좁혀 다시 놓입니다. 아무것도 가리지 않습니다. 핀을 풀면 지금처럼 떠 있는 패널(i)로 돌아갑니다. 고정 여부는 기억합니다.
  2. 2패널을 정리 도구로: 폴더·캐릭터를 「이름 ×」 칩으로 보여 주고 +로 바로 더합니다. 자동 태그는 테두리만 있는 칩(점수 표시)으로 구분하고, 누르면 지금처럼 작은 창으로 자세히 봅니다. 즐겨찾기 하트는 미리보기 옆에 둡니다. 비어 있던 아래쪽에 같은 게시물 줄이 이어집니다.
  3. 3「정리할 것」: 왼쪽 목록에 이미 있는 화면들(미분류, 작가 미상, 닮은 작가 후보, 휴지통)을 개수와 함께 모아 둡니다. 정리할 거리가 늘 한눈에 보입니다. 지금은 홈이나 다른 화면을 거쳐야 갑니다.
  4. 4크기 막대: 「보기」 메뉴를 열지 않고 섹션 바에서 바로 그림 크기를 바꿉니다. 「보기」 메뉴의 나머지 설정은 그대로입니다.
  5. 이번에 넣지 않은 것: 별점과 메모는 지금 에셋 데이터에 없는 항목이라 새 기능이 됩니다(원하시면 따로). 색 팔레트·색 검색은 그림마다 색을 뽑는 작업이 필요해 나중으로 둡니다.
