Removed: 최근 연 폴더 and the always-open search field (now the bar's magnifier). The review entries (캐릭터 후보, 유사 이미지) leave the list and become one small 확인 N button in the bar, shown only when something waits. The segment control and the 분류 label take the PC look. Two ways to make the first view end on a whole row:

  • A · 줄 맞춤: 3 columns. Cover height flexes slightly (between 4:3 and square) so exactly three whole rows fill the screen; the end line says how many more are below, and scrolling snaps by row, so every stop ends cleanly.
  • B · 한 화면에 모두: 4 smaller columns, so up to 12 top-level folders fit on one screen without scrolling; with more, the last tile becomes "+N 더 보기".

Inside a folder, the separate header row (뒤로 · 경로 · 제목 · ⋮) merges into the shared bar, which gives the gallery about 90 px more. The filter chips take the PC look and stay neutral until one is set.

3필터 버튼은 평소엔 조용하게

Today the 카탈로그 필터 chip turns white whenever any filter is stored, and saved 회피 태그 count as filters, so it is white all the time. Proposal: the user's saved 회피 태그 and categories are the default, and the chip stays neutral with them. It turns to the PC's grey "filter on" face with a count only when something differs from that default (another category set, 차단 작품 보기, a temporary tag). The same rule covers Collections' 내 별점. Assumption to confirm: the brief says "Showcase"; the always-white filter button found in the code is the Catalog one (Collections' 쇼케이스 has no filter button).

4자산 뷰어: 위쪽 아이콘이 무엇인지 보이게

Today 분류 uses a tag icon and 앨범 a folder icon, while the Library shows 분류 as folders, so the icons point the wrong way. Both options switch them: 분류 = 폴더, 앨범 = 겹친 사각형. The destructive 휴지통 sits apart behind a divider.

  • A · 아이콘 + 짧은 이름: always labelled (분류 · 앨범 · 정보 · 휴지통). Clearest; uses about 330 px of the 800 px bar.
  • B · 아이콘만 + 처음 한 번 안내: the bar stays minimal; the first time the viewer opens (and again from 정보), a small card names each icon and is dismissed with 확인.

5PC 느낌의 버튼과 조금 더 높은 하단 탐색

Buttons take the PC ui-button recipe: a control face with a 1 px border and a faint top light (secondary), the ivory accent only for the one main action (primary), and muted text that lights up when pressed (quiet). The visible height drops from 44 to 40 px while the touch area stays 44 px. Filter chips lose the white "selected" slab and use the PC's grey filter face with a count. The bottom navigation goes from 56 to 64 px with slightly larger icons and labels (the 8 px lift from 0.8.2 stays).

6스크롤로 더 불러온 타일이 부드럽게 나타남

Each new row fades in from 10 px below over 320 ms, 45 ms apart per tile, and the picture fades in once it is decoded. The tile's place is reserved at its final size first, so nothing moves. Reduced motion shows tiles at once.
