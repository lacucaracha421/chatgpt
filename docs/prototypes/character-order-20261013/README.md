# 캐릭터·그룹 순서 바꾸기 시안 (2026-10-13)

사용자 피드백 12번: PC 시리즈 폴더 맨 위 선반에서 캐릭터와 그룹의 순서를 쉽게 바꾸고 싶다.
시안: `index.html` (앱의 실제 `tokens.css`, `controls.css`, `folder-shelf.css`, `SeriesBrowser.css` 등을 불러온다).

## 지금 상태

- 선반 순서는 그룹 → 그룹 밖 캐릭터 → 기타 → 제안 → 하위 폴더로 고정돼 있다. 그룹은 항상 캐릭터보다 앞이다.
- 캐릭터 카드 우클릭 메뉴의 `위로 이동` / `아래로 이동`은 한 칸씩만 옮긴다(`move_character_folder`, 방향 ±1). 가로 선반인데 문구는 위/아래다.
- 그룹 카드에는 순서 메뉴가 없다. 그룹 순서는 사이드바에서만 바꾼다(끌기, `Alt+↑/↓`, 메뉴). 사이드바의 놓을 곳 표시는 2px 아이보리 줄이다.
- 선반을 마우스로 끌면 가로로 밀린다(`ShelfScroller`). 카드를 끌어 옮기는 동작은 없다.
- 캐릭터를 그룹에 넣고 빼는 방법은 그룹 편집 대화상자의 체크박스뿐이다.
- 저장: 캐릭터 `character_folder_order.position`, 그룹 `character_groups.position`. 사이드바는 시리즈 아래에 그룹 행만 두고(캐릭터 행 없음), 태블릿 고르기 화면도 같은 순서를 읽는다.

## 추천

**안 A(선반에서 바로 끌기) + 규칙 ①(그룹 먼저, 구간 안에서만).**

- 카드를 0.25초 누르고 있으면 들리고, 끌어서 옮긴다. 바로 움직이면 지금처럼 선반이 가로로 밀린다. 짧게 누르면 지금처럼 열린다.
- 놓일 곳은 이웃 카드가 비켜서 생기는 **빈자리**로 보인다. 끄는 카드는 같은 크기로 떠 있고 그림자만 붙는다. 색 줄·확대 없음.
- 캐릭터를 그룹 카드 가운데에 올리면 **그룹에 넣기** 면으로 바뀐다. 그룹 화면에서는 끄는 동안 선반 맨 앞에 **그룹에서 빼기** 자리가 나타난다. 넣기·빼기 뒤에는 “되돌리기” 토스트를 한 번 띄운다.
- 선반 양 끝 48px에 머물면 선반이 저절로 흐르고, 끄는 중에도 휠이 선반을 민다(선반이 휠을 먹는 동작 유지).
- 키보드: `Alt+←/→` 한 칸, `Alt+Home/End` 구간의 맨 앞·맨 뒤(사이드바 `Alt+↑/↓`의 짝). 메뉴는 `앞으로 / 뒤로 / 맨 앞으로 / 맨 뒤로 / 그룹에 넣기 › / 다른 시리즈로 이동…`. 그룹 카드에도 같은 순서 메뉴와 `그룹 편집`이 생긴다.
- 순서는 놓는 즉시 반영하고 뒤에서 저장한다. 실패하면 원래 순서로 돌아가고 한 줄 토스트에 다시 시도. 그룹 순서는 사이드바 그룹 행에도 같은 순간 반영된다.
- 이유: 보이는 카드를 그 자리에서 바로 옮기는 게 “쉽게”에 가장 가깝고 화면이 바뀌지 않아 조용하다. 안 B는 캐릭터가 아주 많은 시리즈에서 크게 정리할 때의 보조 도구로 나중에 더할 수 있다. 두 안은 같은 저장 방식과 표시를 써서 버리는 작업이 없다.

안 B(순서 편집 모드): 시리즈 더보기의 `순서 편집`으로 들어가면 선반 자리가 줄바꿈 격자로 펼쳐지고, 그룹이 멤버까지 펼쳐진 묶음으로 보인다. 끌기와 키보드(`Space` 집기 → 방향키 → `Space` 놓기)로 순서·넣기·빼기를 한 곳에서 하고 `완료`로 한 번에 저장한다. 평소 선반 동작은 바뀌지 않는다.

## 정할 것

1. **방식:** 안 A(추천) / 안 B / A 먼저, 나중에 B 보조.
2. **그룹과 캐릭터:** ① 그룹 먼저, 구간 안에서만(추천, 저장 형식 그대로) / ② 한 줄에서 자유롭게 섞기(저장 형식·태블릿 읽기 경로 변경, 사이드바와 모양이 어긋남).
3. **집는 손짓(안 A):** 0.25초 누르고 있기(추천), 더 짧게/길게. 카드를 위·아래로 살짝 빼내면 바로 집히는 방식을 함께 둘지.
4. **사이드바 그룹 행:** 지금의 2px 아이보리 줄 표시를 같은 “빈자리(행이 벌어짐)”로 바꿀지(추천: 바꿈).
5. **그룹에 넣은 캐릭터의 자리:** 그룹 멤버의 맨 뒤(추천) / 맨 앞.

## 태블릿

- 같은 것: 순서 구간 규칙, 빈자리·떠 있는 카드·넣기 면·빼기 자리의 모양과 문구, 실패 시 되돌림과 되돌리기 토스트(공용 부품).
- 다른 것: 길게 누르기(0.5초) 후 끌기, 메뉴는 아래 시트, 키보드 조작 없음, 가장자리 자동 흐름 폭 64px.
- 데이터: 태블릿에서 순서를 쓰려면 서버 쓰기 경로와 앱 네트워크 허용 목록 추가가 필요하다.

## 구현 메모 (결정 후)

- 캐릭터 순서는 지금 한 칸 이동 명령만 있다. 임의 위치로 옮기려면 그룹의 `reorder_character_groups`처럼 한 구간의 id 목록을 받는 명령이 필요하다(시리즈·그룹 범위 확인, 태블릿 게시 세대 올리기 포함).
- 그룹에 넣기·빼기는 기존 `save_character_group`(revision 확인)을 쓴다.
- `ShelfScroller`의 가로 밀기와 휠 처리는 그대로 두고, 카드 쪽에서 0.25초 누름을 구분해 집기로 넘긴다.
