유사 이미지 · 원본 단서와 권장 버튼

SIM-ORIGINAL-001의 화면 쪽. 작가 계정과 퍼온 계정이 분명히 갈리는 쌍은 자동으로 정리되어 여기 오지 않는다. 남은 쌍에서 고를 때 필요한 단서 네 가지(계정 · 게시 · 해상도 · 크기)를 두 이미지 아래 한 표로 마주 놓고, 단서마다 어느 쪽에 유리한지 가운데에 작은 꺾쇠로 표시한다. 권장을 정한 단서 한 줄은 바탕이 살짝 밝아지고, 이유는 버튼 옆 한 문장. 권장 버튼만 주 버튼(아이보리)이고, 권장이 없으면 어느 버튼도 강조하지 않는다.

유사 검토는 이번 계획에 있는 영역(SIM-ORIGINAL-001, 10.17 승인)이다. 바뀌는 곳은 두 이미지 아래(기존 파일별 정보 목록과 위쪽 차이 줄을 이 표로 바꿈)와 아래 버튼 줄. 위쪽 이미지/영상 탭과 기존 보관함 검사 줄은 그대로다. 계정·날짜·크기는 예시.

  • 표는 두 이미지 바로 아래, 마주 보는 모양. A 값은 가운데 쪽으로 오른쪽 정렬, B 값은 왼쪽 정렬, 단서 이름은 가운데. 그래서 각 값이 자기 이미지 바로 밑에 있다. 줄 사이는 1px 선 하나.
  • 어느 쪽에 유리한지: 가운데 이름 옆에 그쪽을 가리키는 작은 꺾쇠(‹ ›, 옅은 회색). 유리한 값은 굵게(600), 반대쪽 값은 한 단계 흐리게. 같거나 비교할 수 없으면(게시 시각이 한쪽에만 있음 등) 꺾쇠 없이 둘 다 보통 글씨.
  • 권장을 정한 단서 한 줄만 바탕이 --color-surface로 살짝 밝아지고 이름이 흰 글씨가 된다. 가장자리 띠·밑줄·색 글씨는 쓰지 않는다. 단서끼리 엇갈려도(a: 계정은 새 이미지, 게시는 기존 이미지) 둘 다 보이고, 어느 단서가 이겼는지는 이 줄과 문장으로 안다.
  • 계정 칸: X 핸들(@shiro_neko_art)과 네모 배지 하나 — 작가 / 퍼온 계정 / 알 수 없음. 핸들이 없는 사이트(pixiv · arca · dc)는 사이트 이름을 흐리게 쓰고 배지는 알 수 없음. 배지는 모두 같은 보통 배지(색 없음).
  • 버튼: 순서는 언제나 같다(A 유지 · B 유지 · 둘 다 보관). 권장 쪽만 주 버튼으로 바뀌고 자리는 움직이지 않는다. 쌍이 바뀔 때 다음 쌍의 이미지가 준비되면 표·문장·버튼이 한 번에 바뀐다(빈 화면이나 깜빡임 없음).
  • 기존 패널의 파일 이름, 형식/출처/가져온 날짜/분류 목록과 맨 위 해상도 … · 새 이미지가 … 더 큼 줄은 이 표로 대신한다. 형식은 크기 칸 끝에 작게 붙는다(6.1 MB PNG). 분류·앨범·좋아요는 남기는 쪽으로 옮겨지니 고르는 단서가 아니다.
