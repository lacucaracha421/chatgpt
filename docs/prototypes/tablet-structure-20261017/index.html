태블릿 구조 시안

PC의 오른쪽 클릭·사이드바·여러 장 고르기를 태블릿 손가락 동작으로 옮기는 여섯 가지를 우선순위대로 그렸다. 모두 이미 있는 부품(아래에서 올라오는 시트, 왼쪽 분류 편집 패널, 최근 칩, 선택 바, 뷰어 닫기 줌)을 다시 쓰고, 새로 만드는 것은 그 부품을 잇는 동작뿐이다. 화면은 세로 800 × 1280 태블릿을 줄여 보인다. 각 화면의 크게를 누르면 넓게 본다.

앱의 실제 토큰·컨트롤·태블릿 CSS를 그대로 읽는다. 그림과 이름은 임시 데이터다. 하늘색 원과 빗금은 손가락 위치와 영역을 보여 주는 표시일 뿐 앱 화면이 아니다. 밝은 테마는 앱에 아직 없는 ‘종이’ 테마 값을 빌려 이 페이지에서만 보인다.

A길게 눌러 동작 시트 PC 오른쪽 클릭 메뉴와 같은 항목

폴더 카드, 앨범, 컬렉션 표지·책등, 작가, 최근 칩을 길게 누르면 아래에서 시트가 올라온다. 첫 줄은 무엇에 대한 메뉴인지(그림 + 이름 + 한 줄 정보)이고, 그 아래는 PC에서 같은 것을 오른쪽 클릭했을 때와 같은 항목, 같은 순서, 같은 낱말이다. 사용자가 PC 전용으로 정한 것(폴더 이동·삭제, 캐릭터 지정, 깊은 캐릭터 정리)만 빠진다. 지우는 항목은 맨 아래에 선으로 떼어 빨갛게 둔다. 시트 모양은 지금의 더보기 시트(BottomSheet + MoreSheet 줄)를 그대로 쓴다. 이미지는 지금처럼 길게 누르면 선택 모드가 되고, 선택 바에 새로 생기는 ⋯가 이미지 메뉴를 연다.

  • 누르는 동안 카드는 지금의 눌림 표시(살짝 어두워짐)만 보이고 커지거나 흔들리지 않는다. 0.45초가 차면 짧은 진동과 함께 시트가 올라온다(140 ms, 지금 시트와 같은 움직임).
  • 시트는 아래로 쓸기, 바깥 탭, 닫기, 안드로이드 뒤로로 닫힌다. 항목을 누르면 시트가 닫히고 그 일을 한다(이름 바꾸기처럼 입력이 필요하면 지금의 입력 시트가 이어서 뜬다).
  • 폴더 안 폴더 선반 카드를 길게 누르면 위 폴더 항목 뒤에 PC 선반 메뉴의 앞으로 · 뒤로 · 맨 앞으로 · 맨 뒤로가 한 묶음 더 붙는다. 캐릭터 그룹 카드는 정리 항목이 모두 PC 전용이라 시트를 열지 않는다.

C최근 목적지 한 번 탭 분류 시트 · 앨범 시트 · 뷰어 분류 편집

여러 장을 고른 뒤 분류나 앨범에 추가를 열면 맨 위에 최근 칩 줄이 있다. 칩 하나를 누르면 바로 적용된다(적용 버튼 없음). 누른 칩이 그 자리에서 초록으로 잠깐 물들고 아이콘이 체크로 바뀐 뒤, 시트가 0.9초 뒤 스스로 닫힌다. 성공 알림 창은 따로 띄우지 않는다(DESIGN §12). 칩은 폴더 칩과 같은 부품이다. 고른 사진이 모두 이미 들어 있는 곳은 흐리게 두어 누를 수 없다.

B폴더 서랍 PC 사이드바에 해당 사용자 확인 필요

에셋 화면 상단바 왼쪽의 ☰ 버튼으로만 연다. 화면 가장자리를 밀어 여는 방식은 안드로이드 제스처 뒤로가기와 겹쳐서 쓰지 않는다. 서랍은 뷰어의 분류 편집에 쓰는 왼쪽 전체 높이 패널을 그대로 쓰고, 안의 순서는 PC 사이드바와 같다: 빠른 보기 → 고정 → 최근 → 폴더 트리 → 앨범. 트리는 FOLDER-NAV-001 규칙대로 지금 위치의 경로 하나만 펼쳐 있고, ▸로 다른 갈래를 펼치면 같은 단계의 갈래는 접힌다. 이름을 누르면 그곳으로 가고 서랍이 닫힌다.

이전 결정을 뒤집는 제안이다. 2026-10-17 폴더 탐색 시안에서 태블릿은 ‘트리 없이 칩만’으로 정했다. 서랍을 넣으려면 사용자의 허락이 먼저다. 허락이 없으면 B 없이 C·D·E만 진행해도 된다.

D선택 강화 전체 선택 · 길게 눌러 끌어 범위 선택

선택 바의 개수 바로 뒤에 전체 선택이 생긴다. 지금 보고 있는 목록 전체(아직 안 불러온 부분 포함, 예: 1,284개)를 고르고, 다 골라진 동안에는 탭처럼 굵게 보인다. 그리고 길게 누른 뒤 손을 떼지 않고 끌면 처음 타일부터 손가락 아래 타일까지가 한 번에 골라진다(구글 포토 방식). 이미 고른 타일에서 시작하면 반대로 빼기가 된다. 손가락이 화면 위·아래 가장자리 96px 안에 들어가면 목록이 스스로 스크롤되고, 깊이 들어갈수록 빨라진다.

E뷰어 아래로 쓸어 닫기

확대하지 않은 사진을 아래로 끌면 사진이 손가락을 따라 내려오며 조금 작아지고, 검은 바탕이 옅어져 뒤의 목록이 비친다. 120px 넘게 내리거나 빠르게 튕기고 놓으면 지금 쓰는 닫기 줌(사진이 원래 타일로 줄어드는 320 ms 움직임)으로 닫힌다. 덜 내리고 놓으면 되튐 없이 제자리로 돌아간다. 상단바에서 시작한 끌기는 해당 없다(상단바 버튼, 안드로이드 알림창과 겹치므로). 확대한 사진은 지금처럼 끌면 사진 안을 움직인다. 위로 쓸기(필름 띠 키우기)와 좌우 넘기기는 그대로다.

F뒤로 = 방문 기록 사용자 결정 필요

지금 태블릿의 뒤로(안드로이드 뒤로와 상단바 ←)는 상위 폴더로 올라간다. 아래로 하나씩 들어간 경우에는 그게 곧 온 곳이라 문제가 없다. 차이는 건너뛰었을 때다: 최근 칩, 찾기, 서랍, 고정, 홈 바로가기로 멀리 간 뒤 뒤로를 누르면, 지금은 처음 보는 상위 폴더가 나온다. 제안은 PC의 마우스 뒤로가기처럼 온 곳으로 돌아가기(그곳의 스크롤 위치까지)이고, 상위 폴더는 상단바 경로를 눌러 간다.

게헨나 캐릭터 › 블루 아카이브— 최근 칩 → 하우징 게임 스크린샷 › 파이널 판타지 XIV— 뒤로 → 지금: 파이널 판타지 XIV/제안: 게헨나
  • 기록은 지금 탭(에셋) 안에서만 쌓는다. 다른 탭으로 가는 것은 기록에 넣지 않는다(DESIGN §9와 같음). 기록이 없으면 지금처럼 상위 폴더, 맨 위에서는 홈으로.
  • 선택 모드, 시트, 서랍, 뷰어가 열려 있으면 뒤로는 그것부터 하나씩 닫는다(지금과 같음).
  • 고를 수 있는 길: ① 안드로이드 뒤로와 ← 모두 방문 기록(권함, PC와 같은 뜻) ② 안드로이드 뒤로만 기록, ←는 상위 폴더(안드로이드의 ‘위로’ 관례) ③ 지금 그대로.

바탕 세 가지 위 여섯 가지를 받치는 공용 부분

동작 목록 하나

대상별 항목(아이디, 낱말, 아이콘, 위험 여부, PC 전용 여부)을 한 모듈에 둔다. PC 오른쪽 클릭 메뉴와 태블릿 시트가 같은 목록을 읽고, 태블릿은 PC 전용 표시가 붙은 항목만 거른다. 낱말이 한 곳에서 정해지므로 지금의 ‘이름 변경 / 이름 바꾸기’, ‘삭제 / 컬렉션 삭제’ 같은 엇갈림이 사라진다. 자리: src/shared/(규칙과 낱말은 늘 공용, DESIGN §12).

길게 누르기 하나

한 훅이 시간과 허용 흔들림을 정한다: 0.45초, 10px(지금 갤러리 값). 찰 때 짧은 진동, 스크롤이 시작되면 취소, 뒤따르는 탭은 무시, 시스템 메뉴는 막는다. 지금 제각각인 값(갤러리 450 ms, 카탈로그 고정 500 ms)을 하나로 맞춘다. PC 선반 끌어 옮기기의 250 ms는 마우스용이라 따로 둔다.

목적지 하나

폴더·캐릭터 그룹·앨범을 같은 모양(종류, 아이디, 이름, 아이콘, 색, 경로)으로 다룬다. 이 하나가 최근 칩(간 곳), 시트의 최근(넣은 곳), 서랍, 뒤로 기록(간 곳 + 스크롤), 찾기 결과를 함께 먹인다. 지운 폴더는 빠지고 이름을 바꾸면 따라간다(최근 폴더 규칙 그대로).

확인하지 못한 것

  • 헤드리스 Edge의 정지 화면과 마우스 동작으로만 봤다. 손가락 느낌(0.45초, 120px, 자동 스크롤 속도)은 실제 태블릿에서 맞춰야 한다.
  • 안드로이드 제스처 뒤로가기가 화면 양쪽 가장자리에서 시작한다는 전제로 가장자리 밀기를 뺐다. 이 태블릿의 탐색 설정(제스처/버튼)은 확인하지 않았다.
  • 폴더 고정을 태블릿에서 쓰는 서버 길이 없다는 것은 코드(PC 설정을 태블릿에 게시만 함)에서 읽은 것이고, 서버 쪽은 보지 않았다.
  • 태블릿에 ‘이 컬렉션에서 빼기 / 대표 이미지로 지정’이 필요한 이미지 컬렉션 화면이 있는지는 확인하지 않았다.
  • 밝은 테마는 앱에 없는 ‘종이’ 값을 이 페이지에서만 빌렸다. 앱은 어두운 테마 하나뿐이다.
