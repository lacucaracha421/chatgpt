# 찾기 우선순위 시안 (2026-10-13)

사용자 의견 9번: 자연어 검색은 뒤로 미루고 태그·폴더·캐릭터를 먼저 보여 줄 것. ‘레베카’를 치고 Enter를 누르면 바로 그곳으로 가야 하고, 컬렉션 탭에서는 컬렉션 결과가 먼저 나와야 한다. ‘화면’과 ‘명령’이 어떻게 다른지도 알 수 없다는 의견.

시안: `index.html` (앱의 실제 `tokens.css`, `controls.css`, `chrome.css`, `findEntry.css`를 불러온다).

## 지금 상태 (코드 기준)

- 그룹은 탭과 상관없이 늘 같은 순서로 나온다: 이미지 내용 → 이 화면에서 → 작품 → 작가 → 메모 → 폴더(폴더·앨범·캐릭터) → 확인할 것 → 최근 연 것 → 이동 → 실행 (`src/shared/findModel.ts`).
- Enter는 강조된 줄을 열고, 처음 강조는 늘 첫 줄이다. 그래서 2글자 이상 치면 ‘장면 찾기’(자연어)가 맨 위에 오고 Enter도 그쪽으로 간다.
- 자동 태그는 ‘실행’ 그룹 맨 아래로 들어가 있고, 범위 칩은 ‘명령’이다. 화면 어디에도 ‘태그’라는 말이 없다.
- ‘화면’ 칩은 ‘이동’ 그룹(홈, 통계, 설정 등)을, ‘명령’ 칩은 ‘실행’ 그룹(파일 가져오기, 절약 모드)과 태그를 가리킨다. 게다가 설정 안에도 ‘설정 · 화면’이 따로 있다.
- 작품과 작가 그룹 안에서는 얼마나 잘 맞는지로 정렬하지 않는다. 앞부분이 같은 이름을 먼저 올리는 정렬은 폴더 그룹에만 있다.
- 발매 캘린더, 쇼케이스, 신간은 찾기에 없다. 로컬 망가 제목과 AV 배우 이름도 찾기 대상이 아니다.
- 단축키는 `Ctrl+Q`다 (2026-10-05에 Ctrl+K를 대체).

## 추천

1. **맨 위 한 줄.** 모든 그룹을 통틀어 가장 잘 맞는 이름 하나를 그룹 제목 없이 맨 위에 두고, 처음부터 강조해 둔다. Enter를 누르면 그 줄이 열린다.
2. **순서 규칙.** (1) 강한 일치가 약한 일치보다 늘 위에 온다. 강한 일치는 이름이 완전히 같거나 앞부분 또는 단어 첫머리가 같은 경우이고, 약한 일치는 이름 중간에 들어 있거나 초성만 맞는 경우다. (2) 강한 일치끼리는 지금 탭의 우선 그룹이 위에 온다. (3) 같은 그룹 안에서는 완전히 같음 → 앞부분 같음 → 최근에 연 것 → 이미지·작품이 많은 것 → 짧은 이름 순이다. (4) 강하게 맞는 이름이 하나도 없으면 ‘이 화면 검색’ 줄(컬렉션·망가·메모)이나 ‘장면 찾기’ 줄(에셋·홈)이 맨 위에 온다.
3. **탭별 우선 그룹.** 에셋은 폴더·캐릭터 → 태그 → 작가. 컬렉션은 작품(지금 고른 종류 먼저) → 이 화면 검색. 망가는 만화 작품 → 로컬 망가/카탈로그 검색. 메모는 메모 제목 → 본문 검색. 설정 쪽 화면은 메뉴. 범위 칩의 순서는 탭이 바뀌어도 그대로 둔다.
4. **화면/명령 → ‘메뉴’ 한 그룹** (A안). 칩은 `전체 · 작품 · 폴더·캐릭터 · 태그 · 작가 · 메모 · 메뉴`. 태그는 자기 칩을 따로 갖는다. 설정 하위 메뉴는 `설정 › 화면`처럼 표시한다. 발매 캘린더, 쇼케이스, 신간을 메뉴에 새로 넣는다.
5. **장면 찾기는 맨 끝 한 줄** (A안). 에셋·홈에서만 나온다. 미리보기 6칸은 그 줄이 강조되거나 맨 위가 됐을 때만 불러오고, `Ctrl+Enter`를 누르면 바로 장면 찾기가 열린다. 컬렉션·망가·메모에서는 나오지 않는다.

예시 화면: 레베카(에셋), 아스나(에셋, 같은 이름 캐릭터 둘), 젤다(컬렉션과 에셋 비교), 발매(컬렉션), 설정(망가), 비 오는 거리(에셋, 맞는 이름 없음).

## 태블릿

태블릿 찾기 시트는 PC와 같은 `findGroups`를 쓰므로 순서 규칙, 그룹 이름, 칩 이름이 그대로 따라온다. 지금 탭 정보만 넘기면 된다. 맨 위 한 줄은 64 높이 두 줄 행이고 화면 키보드의 검색 키로 열린다. ‘메뉴’ 칩은 태블릿에도 두되, PC 전용 줄(파일 가져오기, 절약 모드)은 뺀다. `Ctrl+Enter`는 태블릿에 없다.

## 사용자가 정할 것

1. 화면/명령: A ‘메뉴’ 하나로 합치기 (추천) / B ‘이동’과 ‘실행’ 두 개로 두고 이름만 맞추기.
2. 장면 찾기: A 맨 끝 한 줄 + 필요할 때만 미리보기 + Ctrl+Enter (추천) / B ‘장면’ 칩을 골랐을 때만 나오기.
3. 에셋 탭에서 같은 이름이 캐릭터·폴더·태그에 모두 있을 때 맨 위 순서: 추천은 캐릭터 → 폴더 → 앨범 → 태그 (가는 곳을 먼저, 필터는 그다음). 태그를 먼저 원하면 바꾼다.
4. 새로 넣을 이름: 발매 캘린더·쇼케이스·신간 메뉴 줄은 추천한다. 로컬 망가 제목과 AV 배우 이름까지 이번에 찾기에 넣을지는 결정이 필요하다 (넣으면 작업 범위가 늘어난다).
