메모 — 제목 줄 고정 + 구간 접기 (2026-09-29)

결정: 새 종류 대신 보통 메모에서 `#`으로 시작하는 줄은 자동으로 고정 줄. 고정 줄은 편집 중에도 그대로 보이고, 편집은 구간(고정 줄 사이)마다 따로 — 누른 구간만 입력칸으로 바뀌고 나머지는 그대로라 흔들리지 않음. 고정 줄을 누르면 그 구간이 접힘/펼침(기기에 기억), 오른쪽 … 메뉴: 이름 바꾸기 · 위로/아래로 · 고정 풀기(보통 줄로) · 구간 삭제. 저장은 지금처럼 Markdown(`## nai`) 그대로라 서버 변경 없음, 예전 앱에서도 읽힘. 맨 아래 “＋ 제목 추가”.

PPC — “확장” 구간을 편집하는 중, “모바일” 접힘, … 메뉴 열림

제목 옆 흐린 숫자는 그 구간의 줄 수. 편집 중인 구간만 면 + 파란 밑줄. Esc 또는 바깥 클릭 = 구간 편집 끝.
