Claude 의견 표시

Claude는 동의만 합니다. 아니라고 하거나 모르겠다고 하면 화면에는 아무것도 생기지 않고, 추천은 지금과 똑같이 남습니다. 동의한 추천에는 Claude 동의 표식이 붙고, 같은 캐릭터 묶음 안에서 앞으로 옵니다.

정한 것

표식 글자: “Claude 동의”Claude는 사용자가 고른 서비스 이름이라 TMDB · IGDB처럼 그대로 씁니다. 내부 인식기 코드(S36 · B36 · PixAI)와 모델 버전(Haiku)은 쓰지 않습니다. “맞음”은 사용자의 판단 단어라서 피했습니다.
자리: 이미지 왼쪽 위, scrim 배지크게 보기는 오른쪽 위, 아님 표시는 가운데라 겹치지 않습니다. 이미지 위에 떠 있어서 생겨도 타일 크기와 줄바꿈이 바뀌지 않습니다.
순서: 묶음 안에서 동의한 것 먼저나머지는 지금 순서 그대로. 캐릭터 묶음 순서도 그대로. 목록을 연 뒤에 도착한 의견은 표식만 제자리에서 나타나고, 자리 이동은 다음에 열 때.
이유 글: 한 장씩 보기에서만격자와 태블릿 카드에는 배지만. 한 장씩 보기 패널에 meta 한 줄로 “Claude · …”. 마우스를 올리면 뜨는 말풍선은 쓰지 않습니다(§9).
묶음 머리: “Claude 동의 2”0이면 아무것도 쓰지 않습니다. 확인 개요(캐릭터 행)에도 같은 문구가 붙습니다.
설정: 라이브러리 › Claude 의견키 · 켜기 · 월 한도 · 상태를 한 묶음에. 태블릿에는 설정이 없습니다(PC가 키를 갖고 작업을 돌림).

태블릿은 PC와 같은 Badge와 같은 문구를 씁니다. 다른 점은 자리 하나뿐입니다.

카드 왼쪽 위는 오른쪽으로 밀 때 “다음/맞음” 도장이 뜨는 자리라서, 배지는 이미지 위가 아니라 캡션의 이유 배지 줄 맨 앞에 둡니다. 카드는 내용이 바뀌는 동안 새 의견을 받지 않으므로(피드에서 함께 옴) 이 줄은 중간에 늘어나지 않습니다.

이 화면을 만지는 김에 둥근 알약 모양 .review-chip을 공용 Badge(24px, 사각 2px)로 바꿉니다 — §12 “같은 조각을 만질 때 태블릿 사본을 교체”.

이유 글은 태블릿에 보이지 않습니다. 길게 누르기는 카드 끌기와 겹치고, 카드에는 펼칠 패널이 없습니다.

순서: 캐릭터 하나로 열면(캐릭터 칩 “확인 N”) 동의한 것이 먼저. 전체·시리즈로 열면 각 캐릭터가 차지하던 자리 안에서 동의한 것이 먼저 옵니다. 순서는 PC가 피드를 만들 때 정합니다.
