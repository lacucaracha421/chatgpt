# 홈 · 더보기 · 찾기 (2026-10-02)

Mockup for backlog `PC-POLISH-20261002` items 12 (Home) and 4 (더보기 · 찾기). Accepted as drawn by the user on 2026-10-02.

- 홈: left column 「오늘 할 것」 (non-zero review counts, ledger reminders, open items of pinned 할 일 notes, connection
  problems only), right column 2-week new releases with D-n and 「1년 전 오늘」. Moved out: asset totals (통계), healthy
  status (top-bar 확인), artist/AV performer picks (작가), memo cards and ledger numbers (메모).
- 더보기: opens beside the rail button, bottom-aligned; no header or close button; outside click / Esc closes.
- 찾기 (Ctrl K): one field finds works, artists, note titles, folders, screens and commands from data already on the
  device; scope chips; the current screen's own search is the first row; empty query shows 확인할 것 + 5 recent items.

Update 2026-10-02 (after a comparison of Plex, Jellyfin, Kavita, Komga, Mihon, Steam, Google/Apple Photos, YNAB, Rocket
Money and others; accepted by the user): add 「새로 나옴」 at the top of the right column (works whose release date passed
since the last visit and new chapters of bookmarked catalog titles, marked NEW until opened) and a one-line subscription
total at the top of 「오늘 할 것」 (this month's total, next charge in N days). No 「이어 읽기」: the user rarely resumes
reading. Motion: rows that appear or resolve collapse/expand in 140 ms; refreshes never blank the screen.
