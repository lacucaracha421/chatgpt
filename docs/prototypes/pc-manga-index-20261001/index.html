망가 목차 — 자주 찾는 태그·작가와 로컬 폴더

망가 라운드 5번째 조각(왼쪽 목차)과 6번째(태블릿)의 시안입니다. 9월 29일에 정한 A·D 화면을 지금의 섹션 바 구조에 맞춰 다시 그리고, 누르면 어떻게 되는지를 정했습니다. 직접 눌러 보세요: 태그·작가 행, 행에 마우스를 올리면 나오는 핀, 「모두 보기」, 위의 출처 전환, 로컬의 「목록 보기」.

  1. 무엇이 모이나: 북마크한 작품들에 붙은 태그와 작가를 세어, 많은 순으로 8개씩 보여 줍니다. 숫자는 그 태그가 붙은 북마크 작품 수입니다. 따로 기록하는 건 없고 북마크만 보고 셉니다.
  2. 누르면: 그 태그(또는 작가)로 카탈로그를 바로 거릅니다. 상단바 제목 옆에 「× 네토라레」 표시가 붙고, ×나 같은 행을 다시 누르면 풀립니다. 하나만 고를 수 있습니다(여러 개는 검색창에서).
  3. 고정: 행에 마우스를 올리면 핀이 나오고, 누르면 맨 위 「고정」 칸으로 올라가 늘 그 자리에 있습니다. 고정은 라이브러리에 저장되어 다른 기기와 재설치 후에도 남습니다. 이 저장 칸 때문에 라이브러리 구조 변경(마이그레이션)이 필요합니다.
  4. 로컬: 왼쪽은 망가 폴더의 첫 단계 폴더(작가·서클)와 작품 수입니다. 디스크에서 사라진 폴더가 있으면 아래에 한 줄 알림이 뜨고, 「목록 보기」에서 골라 백업한 뒤 목록에서만 지웁니다(파일은 이미 없음).
  5. 태블릿: 왼쪽 목차가 없으니 섹션 바의 「필터」 시트 맨 위에 같은 「고정 · 자주 찾는 태그 · 작가」가 칩으로 들어갑니다. 길게 누르면 고정/해제.
  6. 빈 상태: 북마크가 없으면 「북마크한 작품이 생기면 자주 찾는 태그와 작가가 여기에 모입니다」 한 줄만 보입니다.
