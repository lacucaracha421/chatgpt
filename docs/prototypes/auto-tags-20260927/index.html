자동 태그 목업 — PC

PixAI 태거 v0.9가 붙인 자동 태그를 PC 에셋 화면에 보여 주는 안입니다. 이미지 8,915장, 이미지당 평균 54개(점수 ≥ 0.35), 태그 종류 11,737개 기준의 가상 데이터입니다. 자동 태그는 점선 테두리 칩으로, 사용자가 만든 분류 태그(면이 채워진 칩)와 구분합니다. 성적 태그도 다른 태그와 똑같이 보여 줍니다. 이미지는 모두 자리표시용 도형입니다. 창 크기는 1600 × 1000, 정보 패널 폭은 지금 앱과 같은 272px입니다.

1정보 패널의 자동 태그 섹션

자동 태그 섹션은 같은 게시물과 출처 사이에 들어갑니다(아래 패널의 왼쪽 세로선). 공통 규칙: 흔해서 정보가 적은 태그(여자 1명, 단독, 정면 응시, 단색 배경, 흰 배경 …)는 맨 뒤로 보내고 흐리게 표시합니다. 캐릭터 태그는 점수 0.85 이상이고 확정 캐릭터가 없을 때만 추정 표시와 함께 맨 앞에 나오며, 확정 캐릭터가 있으면 숨깁니다. 칩을 누르면 그 태그로 거른 에셋 목록이 열립니다. 사전에 없는 태그는 영어(밑줄 → 띄어쓰기)로 보입니다.
  • 추천: A. 가장 단순하고 패널 높이가 일정합니다. B는 사전 약 500개에 분류를 더 달아야 하고, 사전 밖 태그가 “기타”로 몰립니다. C는 가장 작지만 눌러서 거르기·빼기가 불편합니다.

2잘못된 태그 편집

잘못 붙은 태그는 칩에 마우스를 올리면 나오는 ✕로 이 에셋에서만 뺍니다. 뺀 태그는 나중에 다시 태깅해도 다시 붙지 않고, 바로 아래에 되돌리기 알림이 뜹니다. + 태그 추가는 태거 어휘(한국어·영어)에서 골라 붙이며 라이브러리 개수를 함께 보여 줍니다. 직접 붙인 태그는 실선 테두리 + 작은 점으로 구분합니다.
  • 추천: B (빼기 + 추가). C의 전체 숨기기와 여러 개 선택 편집은 쓰임이 확인되면 나중에 더합니다. 전체 숨기기 목록은 설정에서 되살릴 수 있어야 합니다.

3태그로 찾기 (에셋 화면)

에셋 화면에는 늘 떠 있는 검색창이 없다는 규칙(pc-design-reference §5)을 지킵니다. 자동 태그는 자유 문장 검색이 아니라 정확한 태그 필터입니다. 여러 태그는 모두 포함(AND)으로 합치고, 칩 앞의 +/−를 눌러 제외로 바꿉니다. 결과 개수는 제목 옆에 바로 보입니다. 정보 패널의 칩을 누르면 같은 필터가 적용된 상태로 이 화면이 열립니다.
  • 추천: A (찾기 팔레트에서 추가, 제목줄에 필터 배지). 지금의 찾기(Ctrl+K)와 검색 해제 규칙을 그대로 씁니다. B의 “함께 많이 나온 태그”는 A에도 나중에 붙일 수 있습니다.

4한국어 표시 방식

같은 태그를 세 가지로 적어 봤습니다. 사전(약 500개, 전체 태그 등장의 약 62%)에 있는 태그는 한국어, 없는 태그는 영어로 나옵니다. 검색은 어느 방식이든 한국어·영어를 모두 받습니다.
  • 추천: 한국어만 (마우스를 올리면 영어 이름 + 라이브러리 개수). 칩 한 줄에 가장 많이 들어가고, 영어가 필요할 때만 보입니다.
