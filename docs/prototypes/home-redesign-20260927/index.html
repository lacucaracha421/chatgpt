지금 홈의 문제 — 숫자 하나가 가로 한 줄을 통째로 차지하고(자산 현황 숫자 5개 = 5줄), 조용한 카드도 카드 한 장(“새 신간 없음”, “받은 파일 · 보낼 파일 없음”)을 씁니다. 그래서 한 화면에 보이는 게 적고 이미지는 거의 없습니다. 세 방향 모두 같은 원칙을 따릅니다: 숫자는 타일 한 칸(선으로 나눈 한 면), 조용한 것은 한 줄로 접기, 이미지는 신간 · 발매 표지와 다시 보기(예전 자산)만 — 최근 저장 이미지는 쓰지 않습니다. 이미지는 모두 원래 비율 그대로(다시 보기는 줄 맞춤 배치, 자르지 않음), 설명은 이미지 아래에 둡니다. 큰 틀은 “바쁨” 상태(확인할 것 있음 · 새 권 나옴 · 전송 중), 오른쪽 작은 틀은 “평온” 상태에서 접히는 모습입니다. 제목 · 이미지는 모두 가짜 예시입니다.
