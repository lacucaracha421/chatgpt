PC · 배우 프로필 직접 편집

배우 페이지(A안 왼쪽 기둥) 그대로, 이름 옆 연필과 배우 관리 ⋯ → 프로필 편집 두 곳에서 엽니다. 편집은 대화상자 하나 — 이름, 생년월일, 키, 사이즈, 컵·가슴, 활동, 링크. 손댄 칸만 직접 입력이 되고 StashDB 값이 바로 아래 보이며 되돌리기로 다시 StashDB를 따라갑니다. 저장 후 페이지에는 항목 이름 뒤에 조용한 “· 직접 입력” 한 단어만 붙습니다. ← 목차

① 들어가는 곳 1440 × 900 · 배우 관리 ⋯ 메뉴를 연 상태

1이름 옆 연필 — 즐겨찾기 별 왼쪽, 늘 보이는 흐린 아이콘(메모 연필과 같은 모양). 2배우 관리 ⋯ → 프로필 편집 — 사진 바꾸기와 메모 편집 사이. 단축키 E. 둘 다 같은 대화상자를 엽니다.

② 편집 대화상자 StashDB를 따르는 칸과 직접 입력한 칸이 섞인 상태 · 링크 하나를 추가하며 입력 중

따르는 칸은 StashDB 값이 그대로 들어 있고 표시가 없습니다. 값을 고치는 순간 그 칸 이름 오른쪽에 직접 입력, 아래에 StashDB 160 cm · 되돌리기가 생깁니다. 칸을 지우고 저장하면 “비움”이라는 직접 입력 값이 됩니다(→ 상태 화면). 링크는 목록 전체가 한 칸처럼 움직입니다. 사이즈는 화면과 같은 cm로 입력합니다. 왼쪽 아래 모두 StashDB 값으로는 직접 입력이 하나라도 있을 때만 보입니다.

③ 저장한 뒤 키 · 활동 · 링크를 직접 입력 · “직접 입력”을 눌러 비교 창을 연 상태

값은 저장 즉시 바뀝니다(기다리는 표시는 0.4초가 지나도 안 끝날 때만 “대기”). 항목 이름 뒤 · 직접 입력은 이름보다 한 단계 밝은 글자일 뿐 색 줄·배지는 없습니다. 누르면 작은 창에 내 값과 StashDB 값이 나란히 나오고 되돌리기 / 편집을 고를 수 있습니다. 링크 줄 끝의 표시도 같습니다.
