편집 화면 바깥에서 생기는 상태들. 모두 기존 배우 정보 저장(즐겨찾기·메모)과 같은 방식을 그대로 씁니다. ← 목차

⑦ 저장 중 · 충돌 PC 왼쪽 기둥 · 태블릿 머리 부분

저장을 누르면 창이 바로 닫히고 페이지 값이 즉시 바뀝니다. 0.4초 안에 끝나면 아무 표시도 없고, 그보다 오래 걸릴 때만 StashDB 줄 아래에 대기가 나타납니다(나타나면 짧게 유지해 깜빡이지 않음). 다른 기기에서 먼저 바뀌었다면 같은 자리에 충돌 · 다른 기기에서 배우 정보가 바뀌었습니다 · 덮어쓰기 · 버리기 — 지금 태블릿 배우 페이지의 줄과 같은 모양입니다. 충돌을 정리하기 전까지 연필은 눌리지 않습니다.

⑧ StashDB ▾ 메뉴 새로고침은 직접 입력을 건드리지 않음 · 한 번에 모두 되돌리기

StashDB 새로고침은 따르는 칸만 새 값으로 바꾸고 직접 입력한 칸은 그대로 둡니다. 직접 입력이 있으면 메뉴에 모두 StashDB 값으로가 생깁니다(개수 표시). 다른 사람으로 바꾸기나 연결 해제를 해도 직접 입력한 값은 남습니다.

⑨ 비우기 · 잘못된 주소 같은 대화상자

따르는 칸을 비우고 저장하면 비움이라는 직접 입력이 됩니다 — StashDB에 값이 있어도 페이지에 그 항목이 나오지 않습니다(예: 컵 F가 틀렸지만 맞는 값을 모를 때). 되돌리기로 다시 StashDB를 따릅니다. 링크 주소가 http(s)로 시작하지 않으면 빨간 테두리와 한 줄 설명, 저장은 그 줄을 고칠 때까지 막힙니다.

⑩ StashDB 연결이 없는 배우 모든 칸이 내 값 · 표시와 비교 줄 없음

StashDB에 없는 배우도 같은 양식으로 편집합니다. 비교할 값이 없으니 직접 입력 표시, 비교 줄, 되돌리기, “모두 StashDB 값으로”가 모두 빠집니다. 페이지에도 “· 직접 입력”을 붙이지 않습니다(전부 내 값이므로). 나중에 StashDB에 연결하면 이미 채운 칸이 직접 입력으로 남고 빈 칸만 StashDB를 따릅니다. 그때부터 남은 칸에 “· 직접 입력”이 붙습니다.
