배우 관리

⑤ 편집 시트 위 36px만 남기고 올라옴 · 아래로 쓸어 닫기

PC 대화상자와 같은 양식 조각, 두 칸 배치 그대로. 키·생년월일·사이즈·활동 칸은 숫자 키패드가 뜹니다. 아래 막대(취소 · 저장)는 키보드가 올라오면 키보드 바로 위에 붙습니다. 저장하지 않고 쓸어 닫으면 바뀐 게 있을 때만 “편집한 내용을 버릴까요?”를 묻습니다.

⑥ 저장한 뒤 왼쪽: 페이지 · 오른쪽: “직접 입력”을 누르면 뜨는 작은 시트

PC와 똑같이 항목 이름 뒤 “· 직접 입력”. 태블릿에서는 누르면 아래에서 작은 비교 시트가 올라와 내 값과 StashDB 값을 나란히 보여 주고, StashDB 값으로 되돌리기와 편집을 고릅니다.
