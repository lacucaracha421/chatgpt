메모 · 가계부 다듬기

메모는 마크다운 없이 쉽게 쓰고 지우는 섹션 메모, 가계부는 구독 · 사고 싶은 것 · 예산이 한눈에 보이는 화면입니다. 위에서 메모/가계부를 바꿔 보고, 화면 안을 직접 눌러 보세요(완료 표시, 섹션 골라 보기, 섹션 복사, 항목 옮기기, 구독 눌러 상세).

보기
  1. 마크다운 없음: 쓴 그대로 보이고 읽기/편집 화면 구분이 없습니다. 열면 바로 커서가 마지막 항목 끝에 있습니다.
  2. 섹션은 칸: 「모바일 앱」「PC 앱」처럼 제목 줄로만 보입니다(#기호 없음). 아무 줄에서 「섹션으로 만들기」를 하면 그 줄이 섹션 제목이 됩니다 — 지금의 「한 줄 고정」을 대신합니다. 저장은 지금처럼 글자라 PC·기존 메모와 호환됩니다.
  3. 섹션만 보기: 위 칩 줄에서 하나를 누르면 그 섹션만 보입니다. 숫자는 남은 항목 수.
  4. 한 줄 = 한 항목: 앞의 동그라미를 누르면 완료. 완료 항목은 섹션 끝 「완료 N」으로 접힙니다.
  5. 추가: PC는 메모에 바로 씁니다 — 섹션 끝 「+ 추가」나 항목 끝에서 엔터. 태블릿만 엄지 닿는 아래에 빠른 추가 칸(섹션 고르기, 마지막 섹션 기억).
  6. 옮기기 · 복사: 항목 오른쪽 「옮기기」(태블릿은 길게 누르기)로 다른 섹션에. 섹션 제목 줄의 「복사」는 남은 항목만 목록 글자로 복사합니다 — Claude에게 넘길 때 그대로 붙여 넣기.
  7. 지우기: 빈 항목에서 백스페이스 → 윗줄로 합쳐짐. 섹션 제목은 백스페이스로 사라지지 않고 「섹션 풀기」로만.
  1. 맨 위 한 줄 요약: 이번 달 예산 → 고정(구독) → 쓴 돈 → 남은 돈. 막대에 사고 싶은 것을 이번 달에 사면 얼마나 차는지 빗금으로 겹쳐 보여 줍니다.
  2. 구독은 상태로: 매달 · N달마다 · 1년 갱신 · 처음 N달 무료 · 해지 예약(낸 기간 끝까지 사용)을 꼬리표로 표시하고, 오른쪽엔 다음 결제일과 금액. 1년 구독은 월 환산도 함께. 지금 데이터(주기·무료·종료일)로 대부분 표현되고, 가격 변경 이력만 새로 필요합니다.
  3. 이번 달 결제 예정: 날짜순 띠로 보여 주고, 무료 끝나는 날·갱신 전날에 알림.
  4. 사고 싶은 것: 가격·살 곳·중요도·목표 달. 누르면 「이번 달에 사면 남는 돈」을 보여 주고 「샀음」 한 번이면 지출로 기록됩니다.
  5. 지출: 직접 입력은 그대로(외부 가져오기 없음). 오른쪽 아래 목록, 빠른 입력 한 줄.
