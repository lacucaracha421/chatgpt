PC 폴더 · 캐릭터 폴더 (2026-09-29)

승인된 폴더 방향 D(pc-assets-20260929/d.png)를 현재 앱 상단바(제목만 · 전체/이미지/영상 · 정렬 · 보기)에 맞춰 다듬고, 캐릭터 폴더를 같은 틀로 다시 그렸습니다. 미분류 / 전체가 하위 폴더 포함을 대신하므로 보기 메뉴에서 그 스위치를 뺍니다. 선택 막대의 캐릭터 버튼은 어디서나 같은 선택기를 열고, 시리즈 폴더 안에서는 그 시리즈의 캐릭터만 보여 줍니다(목록 끝 “모든 시리즈”, 또는 검색창의 “블아” 범위를 지우면 전체). 폴더는 열 때마다 미분류로 시작합니다. 이미지는 색 블록입니다. index.html?frame=a|b|c|d|e|f로 한 화면씩 볼 수 있습니다.

A일반 폴더 — D 다듬음 (게임 › 리버스)

  • 상단바: 제목만(개수 없음) · 전체/이미지/영상 · 정렬 · 보기. “제안 숨기기”는 선반 라벨 줄 오른쪽으로(선반에만 해당).
  • 선반: 캐릭터 → 제안(점선 · 제안 표시) → 하위 폴더, 한 줄 가로 스크롤(휠 · 끌기 · 화살표). 오른쪽 흐림 그라데이션 대신 카드가 잘려 보이고 화살표만. 마우스를 올린 카드는 그림 모서리에 작은 버튼(캡션 안 움직임).
  • 미분류 · 전체: 선반 바로 아래. 미분류 = 이 폴더에 직접 있고 캐릭터·하위 폴더로 가지 않은 그림(기본값). 전체 = 아래 모두 포함. 그래서 보기 메뉴의 “하위 폴더 포함”은 없어집니다(E). 설명은 ⓘ 안에.
  • 격자: 날짜 머리글 한 모양, 캡션 없음, 마우스를 올리면 모서리에 ★ · ⋯ 와 작가 · 시각 배지.

B캐릭터 폴더 (블아 › 하스미)

  • 폴더 D와 같은 뼈대. 캐릭터에는 하위 폴더가 없으니 선반은 비어서 빠지고, 라벨 줄(이미지 412 · 후보 8 확인)만 남습니다.
  • 제목은 경로(블아 › 하스미), 옆에 편집과 캐릭터 더보기 ⋯(FAULT로 플레이 · 과거 미분류 이미지 갱신 · 일반 폴더로 전환 · S36 자동 분류에서 제외). 인물 확인이 필요하면 편집 버튼 모서리에 빨간 ! 표시.
  • 레퍼런스 · 대표 이미지 · 추천으로 보강은 편집 패널 안에만(F).

C캐릭터 폴더 — 선택 + 캐릭터 선택기 (피드백 4 · 5)

  • 4: 옛 “캐릭터 지정…” 상자와 상단바의 선택 버튼들 대신 에셋과 같은 선택 막대 + 막대에 붙어 뜨는 선택기. “이 캐릭터에서 제외”는 막대 안에.
  • 5: 검색창 앞 블아 범위 배지, 목록은 블아 캐릭터만(추천 → 그룹별), 지금 캐릭터는 “현재”. 목록 맨 아래에 늘 보이는 모든 시리즈 줄. 배지 ×/Backspace나 검색으로도 다른 시리즈에 닿음.

D시리즈 폴더 — 미분류에서 지정, 다른 시리즈로 가는 길

  • 시리즈 폴더(블아)도 A와 같은 화면: 그룹 → 캐릭터 → 제안 → 폴더 선반, 라벨 줄에 “후보 24 확인”(S36).
  • 블아에 없는 이름을 치면 “블아에 없음” 한 줄 뒤에 다른 시리즈 결과(넣으면 그 시리즈 폴더로 옮김)와 새 캐릭터 줄(옛 상자의 “새 캐릭터” 버튼을 대신).

E보기 메뉴 — 하위 폴더 포함이 빠진 모습

  • 배치 · 크기 · 비율 · 정보만. 하위 폴더 포함은 선반 아래 미분류 / 전체가 맡습니다(설명 ⓘ 팝오버 열린 상태 함께 표시).

F캐릭터 편집 패널 — 레퍼런스는 여기에만

  • 편집을 누르면 버튼 아래에 붙어 뜨는 패널(지금의 캐릭터 정보 패널). 이름 · 대표 이미지 · 레퍼런스 12/25(추천으로 보강, 추가) · 설명 · 자동 분류. 확인이 필요한 레퍼런스에는 !, 아래에 “인물 확인 1장”.
