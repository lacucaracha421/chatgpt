  1. 그림만: 파일 이름 · 작가는 타일에 표시하지 않습니다(마우스를 올려도 없음). 필요하면 정보 패널에서 봅니다. (사용자 결정 2026-10-02)
  2. 배지 하나: 영상은 「▶ 0:42」 한 칸만. 하트와 선택 동그라미는 마우스를 올렸을 때만(즐겨찾기 화면에서는 하트 항상).
  3. 날짜 제목은 작은 글자: 가로줄과 장수를 빼고(장수는 마우스를 올리면), 스크롤 중에는 지금처럼 날짜 말풍선.

  7. 폴더 줄은 폴더 맨 위에서만 보이고, 날짜 제목과 겹쳐 쌓이지 않게 합니다.
