설정 · 자동 작업

앱이 알아서 돌리는 큰 갱신·분석·준비·정리 13가지를 설정의 새 구역 「자동 작업」 한 곳에 모은다. 한 줄에 이름 · 마지막 결과 · 언제 도는지(다음 차례) · 켜기/끄기 · 지금 돌리기가 들어가고, 실패한 것은 맨 위 실패 묶음으로 올라온다. Claude 작업은 일부러 뺐다. PC만(태블릿은 나중).

설정 화면은 이번 계획에 있는 영역이다(Settings 개편은 Foundation 롤아웃 첫 화면). 행 모양·색·글자 크기는 앱의 실제 CSS(SettingsRow, SectionLabel, Switch, 조용한 Button)를 그대로 읽고, 새로 생기는 것은 열이 고정된 작업 행 하나뿐이다. 시각·숫자는 모두 예시(지금 10.27 15:02).

A. 자동 작업 구역 1280 폭 · 보통 상태 · 오른쪽 버튼을 눌러 보면 실행 순서대로 바뀐다

실행 중 1(게임 정보) · 실패 1(찜·신간) · 대기 수(클라우드, 영상) · 나머지 쉬는 중

지금 갱신을 누르면 처음 400 ms 동안은 버튼만 잠기고 아무것도 바뀌지 않는다. 그보다 오래 걸리면 결과 줄이 갱신 중…으로 바뀌고(시안에서는 400 ms 뒤 그대로 보인다), 끝나면 결과가 한 번에 바뀌며 줄이 잠깐 초록빛으로 물들고 체크가 스며든다. 성공 토스트는 없다. 찜·신간 발매 확인의 다시 시도가 성공하면 그 줄은 제 묶음(새 정보)으로 돌아가고 실패 묶음은 사라진다. 휴지통 자동 비우기의 만료분 비우기는 확인 창을 연다(C).

B. 절약 모드일 때 무거운 작업 5개가 쉬고, 이유가 「언제」 칸에 적힌다

절약 모드가 켜져 있을 때만 구역 맨 위에 절약 모드 한 줄(실제 스위치)이 생긴다. 무거운 작업(게임 정보, 캐릭터 자동 분류, 유사 이미지 준비, 영상 미리보기 준비, 카드 누끼 만들기)은 「언제」 칸이 절약 모드 / 대기 128장으로 바뀐다. 받던 게임 정보는 그 자리에서 멈추고 막대가 남는다(끄면 이어서). 가벼운 작업(카탈로그, 캘린더, 찜·신간, 자동 태그, 책등, 클라우드, 백업, 휴지통)은 그대로 돈다. 지금 실행은 절약 모드에서도 한 번 돈다(직접 누른 것이므로) — 아래 열린 질문 2.

C. 만료분 비우기 확인 되돌릴 수 없으니 창으로 묻는다 · 몇 개인지 먼저 보인다

휴지통에서 보존 기간(30일)이 지난 것만 영구 삭제한다. 제목에 개수, 아래 한 줄에 범위와 남는 개수, 왼쪽에 지워질 것 두 장을 겹쳐 보인다(DESIGN §12 파괴 확인 창). 버튼 낱말은 영구 삭제. 지난 것이 없으면 행의 버튼이 잠기고 「언제」 칸이 30일 지난 것 없음이 된다. 휴지통 전체 비우기는 여기 두지 않는다(휴지통 화면의 휴지통 비우기).

D. 한 줄의 상태들 같은 행 부품 하나로 모두 그린다

열: 이름 / 마지막 결과(남는 폭) · 언제 / 다음(176) · 스위치(40, 없는 작업은 빈칸) · 버튼(120, 오른쪽 맞춤). 열이 고정이라 13줄 내내 스위치끼리, 버튼끼리 세로로 맞는다. 색은 실패 낱말과 실패 수에만(빨강), 끝남의 체크와 잠깐의 물듦에만(초록). 줄 가장자리 색 띠·아이보리 표시·행마다 돌아가는 스피너는 없다. 진행 막대는 상태 패널과 같은 회색 48×4이고 전체 수를 알 때만 붙는다.

지금의 갱신 묶음(카탈로그 · 캘린더 · 자동 태그)은 자동 작업 구역에 같은 줄이 생기므로 한 줄로 줄인다. 실패나 실행 중이 있을 때만 그 수를 적고(실패만 빨강), 없으면 한 줄짜리 이동 행이다. 같은 일을 두 곳에서 돌리는 버튼은 남기지 않는다.

F. 정한 것과 옮기는 것

  • 자리: 설정의 새 구역 「자동 작업」, 둘째 자리(자주 쓰는 것 바로 아래). 13줄은 자주 쓰는 것에 넣기엔 길고, 카탈로그·연결·라이브러리에 흩어 두면 "한눈에 보기"가 안 된다. 바꾸는 곳이 아니라 살펴보는 곳이라 화면·라이브러리보다 위에 둔다. 아이콘은 ArrowPathIcon.
  • 한 주인 원칙: 자동 작업은 돌지 말지와 언제(켜기/끄기, 카탈로그 간격, 지금 실행)를 갖고, 각 구역은 무엇을·어디서(폴더, 서버 주소·키, 넓은 폴더 인식, 보존 기간)를 그대로 갖는다. 같은 스위치를 두 곳에 두지 않는다.
  • 묶음: 실패(있을 때만, 맨 위) · 새 정보 · 분석 · 준비 · 정리. 실패한 줄은 제 묶음에서 빠져 위로 올라가며(140 ms 높이·투명도), 성공하면 돌아간다. 일부 항목만 실패한 대기 수(클라우드 실패 4개)는 올라가지 않고 그 자리에서 빨간 수만 보인다.
  • 시각: 공용 displayDateTime 규칙대로 오늘은 14:20, 어제는 어제 23:10, 그 밖은 10.25. "3분 전" 같은 상대 시각은 쓰지 않는다.
  • 바쁨 글자: 갱신 중…·받는 중… 등은 공용 지연 바쁨 도우미로 400 ms 뒤에만 보이고, 한 번 보이면 잠깐 머문다. 시안의 정지 그림에서는 그냥 보인다.
  • 설명 없음: 줄에는 설명 문장이 없다. 준비 묶음에만 ⓘ 하나(「새 자료가 들어오면 미리 만들어 둡니다. 절약 모드에서는 쉬고, 끄면 이어서 합니다.」).
