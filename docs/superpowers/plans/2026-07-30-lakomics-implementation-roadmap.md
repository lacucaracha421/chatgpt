# Lakomics Implementation Roadmap

이 로드맵은 승인된 `docs/superpowers/specs/2026-07-30-lakomics-core-library-design.md`를 독립적으로 검토할 수 있는 다섯 구현 계획으로 나눈다. 각 단계는 이전 단계의 작동 가능한 결과물 위에 기능을 더한다.

## 1. 핵심 기반

사용자가 라이브러리 폴더를 고르고, 이미지 파일을 앱으로 끌어넣고, 계층형 분류에 연결하고, 정렬된 갤러리에서 볼 수 있게 한다. 안전한 복사, SHA-256 완전 중복 차단, 썸네일, 분류 트리, 화면에 보이는 행만 그리는 갤러리를 포함한다.

상세 계획: `docs/superpowers/plans/2026-07-30-lakomics-foundation.md`

완료 조건:

- Windows에서 Tauri 앱이 빌드되고 실행된다.
- 사용자 원본을 유지한 채 이미지가 라이브러리로 복사된다.
- 같은 파일을 두 번 넣어도 자산은 하나만 생긴다.
- 상위 분류·작품·태그를 만들고 자산을 연결할 수 있다.
- 분류 트리에서 선택한 자산을 justified-row 갤러리로 볼 수 있다.

## 2A. 미디어 금고 안전 기반

한 라이브러리의 동시 실행을 막고, 상태 기반 휴지통과 기본 30일 보존 정책, SQLite 순환 백업과 안전한 복구를 추가한다.

상세 계획: `docs/superpowers/plans/2026-08-01-lakomics-vault-safety.md`

완료 조건:

- 같은 라이브러리를 두 앱이 동시에 열 수 없다.
- 휴지통 이동과 복원이 파일 경로와 메타데이터를 함께 보존한다.
- 기본 30일 자동 삭제를 끄거나 기간을 변경할 수 있다.
- 최근 7일의 SQLite 백업을 복구 화면에서 선택할 수 있다.
- 복구 전 현재 관리 정보를 별도 백업하고 손상된 백업을 거부한다.

## 2B. 중단 복구와 라이브러리 검사

수집 진행 상태를 SQLite에 기록하고, 앱이나 PC가 중단되면 다음 실행에서 안전한 지점부터 이어간다. 사용자가 전체 라이브러리 검사를 실행해 누락·손상 파일을 찾고, 정확히 같은 파일을 다시 넣으면 기존 관리 정보를 유지한 채 복구한다.

완료 조건:

- 여러 파일 수집이 중단된 뒤 이미 완료한 항목을 건너뛰고 이어진다.
- 반복 실패한 파일은 원인과 함께 별도 목록에 남는다.
- 전체 검사가 백그라운드에서 진행되며 앱을 계속 사용할 수 있다.
- 누락·손상 자산의 분류, 좋아요와 출처가 보존된다.
- 정확히 같은 파일을 다시 넣으면 누락 자산이 자동 복구된다.
- 휴지통의 완전 중복은 새 자산을 만들지 않고 복원 여부를 묻는다.

## 2C. 이미지 정리 기능

유사 이미지 검토, 미분류함, 검토 대기와 기본 컬렉션을 추가한다. 현재 구현된 즐겨찾기와 최신순·오래된순·즐겨찾기순·고정 랜덤 정렬은 이 단계에서 실제 대규모 자료로 다시 검증한다.

완료 조건:

- 유사 이미지에서 기존 것 유지·교체·둘 다 저장이 동작한다.
- 미분류 자산과 사용자 판단이 필요한 자산이 서로 다른 목록에 나타난다.
- 자산을 컬렉션에 넣고 빼도 원본 분류는 변하지 않는다.
- 네 가지 정렬이 이미지 50,000개 조건에서도 안정적으로 페이지 처리된다.

## 3. 영상 관리

영상 파일 수집, 썸네일, 해상도·길이·크기 표시와 외부 재생기로 열기를 추가한다. 앱 내부 재생기는 포함하지 않는다.

완료 조건:

- 지원 영상 파일이 이미지와 같은 분류·탐색 흐름에 들어간다.
- 영상 썸네일과 기본 정보가 백그라운드에서 생성된다.
- 영상 자산을 기본 또는 사용자 지정 외부 재생기로 열 수 있다.

## 4. Chromium 확장 프로그램

새 Manifest V3 확장 프로그램, 단계형 두 고리 도넛, 인증된 `127.0.0.1` 연결, X·Pixiv·일반 웹 출처 Adapter를 추가한다.

완료 조건:

- Chrome과 Edge에서 이미지 한 장을 끌어 한 분류 경로로 저장한다.
- 앱이 꺼져 있으면 저장을 쌓지 않고 실행 안내를 표시한다.
- 웹페이지 스크립트는 설치별 비밀 키에 접근할 수 없다.
- X, Pixiv와 일반 웹에서 출처 URL과 수집일이 맞게 저장된다.

## 5. 기존 자료 가져오기와 규모 검증

기존 Lakomics 자료를 복사하는 일회성 가져오기와 이미지·GIF 50,000개, 영상 5,000개 조건의 성능·복구 검증을 완성한다.

완료 조건:

- 기존 원본, 호환 태그·작품, 즐겨찾기, 제목, 출처를 복사한다.
- 기존 자료는 이동하거나 삭제하지 않는다.
- 개수·크기·해시와 실패 이유를 결과표로 보여준다.
- 목표 규모에서 실행 3초, 분류 선택 후 첫 결과 1초 목표를 측정한다.
- 강제 종료 지점별 복구 시험에서 자산 손실과 이중 등록이 없다.

## 이후 제품 계획

컬렉션 전시와 꾸미기, 앱 내부 영상 재생, 만화 읽기는 핵심 라이브러리의 실제 사용 결과를 바탕으로 각각 별도 설계와 구현 계획을 만든다.
