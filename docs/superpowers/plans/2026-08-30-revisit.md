# Revisit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the separate creator and calendar quick views with a single `다시보기` destination containing a fixed daily recommendation slate and direct date/creator browsing.

**Architecture:** Keep UTC instants in `assets.collected_at`, but make local calendar-day ranges explicit at the command boundary. Add a focused Rust `revisit` module that owns activity aggregates, daily slate persistence, candidate selection, reshuffling, and feedback; React renders the completed bundles and browse states without reproducing recommendation policy.

**Tech Stack:** Rust, rusqlite, Tauri commands, React 19, TypeScript, Vitest, Testing Library, existing shared UI and `@tanstack/react-virtual`.

**Spec:** `docs/superpowers/specs/2026-08-30-revisit-design.md`

## Global Constraints

- `collected_at` remains a normalized UTC instant; no asset timestamp migration is allowed.
- Calendar counts and exact-day results use the user's local calendar day converted to explicit UTC start/end bounds.
- The first version uses metadata and local activity only; do not add image embeddings or a new dependency.
- A daily slate contains 6–10 bundles and each bundle targets 6–20 unique assets, shrinking rather than duplicating when candidates are scarce.
- Reshuffling is neutral and must not alter recommendation preference weights.
- The default creator grid contains creators with at least three assets; search and `소규모 작가 포함` cover all creators.
- Preserve row virtualization for the 1500+ creator case.
- Do not launch a migration or recommendation write against `C:\New_lakomics_assets` without separate explicit approval; automated tests use temporary libraries.
- Keep the existing user changes in `app/package.json`, `app/src/styles/global.css`, and `app/src-tauri/Cargo.toml` isolated from feature commits unless a task intentionally touches the same lines.

```ts
export type UtcDateRange = { localDate: string; startUtc: string; endUtc: string };

export function toUtcDateRange(localDate: string): UtcDateRange {
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(localDate);
  if (!match) throw new Error("유효하지 않은 날짜입니다.");
  const [, yearText, monthText, dayText] = match;
  const year = Number(yearText);
  const month = Number(monthText) - 1;
  const day = Number(dayText);
  const start = new Date(year, month, day);
  if (start.getFullYear() !== year || start.getMonth() !== month || start.getDate() !== day) {
    throw new Error("유효하지 않은 날짜입니다.");
  }
  const end = new Date(year, month, day + 1);
  return { localDate, startUtc: start.toISOString(), endUtc: end.toISOString() };
}
```
