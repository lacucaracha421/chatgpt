# Lakomics 자산 앨범 설계

## 목표

일반 분류 폴더와 수동 앨범의 역할을 분리한다. 일반 폴더는 자산의 유일한 직접 소속을 나타내고, 앨범은 파일을 복제하지 않은 채 원하는 자산을 여러 묶음에 수동으로 담는 기능을 제공한다.

향후 게임·만화·작품의 표지, 설명, 대표 이미지와 전시 배치를 갖는 큰 `컬렉션` 기능은 이번 앨범과 별도 모델로 개발한다. 현재 기능에는 `스마트 폴더`나 `컬렉션`이라는 이름을 사용하지 않는다.

## 용어와 범위

### 일반 폴더

기존 `ClassificationEntry` 계층이다. 자산은 일반 폴더에 직접 최대 하나만 연결된다. 하위 폴더에 직접 연결된 자산이 상위 폴더에서도 보이는 것은 조회 규칙이며, 상위 폴더 연결을 중복 저장하지 않는다.

자산에 직접 일반 폴더 연결이 없으면 미분류 상태다.

### 앨범

사용자가 직접 만들고 자산을 수동으로 담는 계층형 목록이다. 한 자산은 여러 앨범에 동시에 들어갈 수 있다. 앨범에 자산을 넣어도 미디어 파일이나 자산 레코드는 복제하지 않고 앨범 연결 메타데이터만 추가한다.

앨범은 자동 조건, 폴더 연동, 규칙 기반 수집 기능을 제공하지 않는다.

### 미래의 컬렉션

게임·만화·작품을 전시하고 감상하기 위한 별도 기능이다. 표지, 설명, 대표 이미지, 작품 단위 정보와 배치 등을 가질 수 있다. 이번 앨범 모델을 미래 컬렉션 모델로 확장하거나 이름만 바꾸지 않는다.

## 데이터 모델

기존 분류 테이블과 `asset_classifications`의 다대다 저장 구조는 유지한다. 데이터베이스에 유일 제약을 추가하지 않고, Library Module의 모든 일반 폴더 연결 변경 경로에서 직접 연결을 최대 하나로 만든다. 이렇게 하면 기존 데이터와 백업 형식을 안전하게 마이그레이션하면서 일반 폴더의 사용자 규칙을 바꿀 수 있다.

앨범에는 별도 테이블을 사용한다.

```text
albums
- id
- name
- parent_id -> albums.id
- icon_key nullable
- color_key nullable
- created_at

asset_albums
- asset_id -> assets.id
- album_id -> albums.id
- primary key (asset_id, album_id)
```

앨범은 부모를 최대 하나만 가지며 순환 계층을 허용하지 않는다. 같은 부모 아래의 앨범 이름은 대소문자를 구분하지 않고 고유하다. 아이콘과 색상은 일반 폴더와 같은 허용 목록을 사용한다.

`asset_albums`는 한 자산과 한 앨범의 연결을 한 번만 저장한다. 자산을 영구 삭제하면 관련 앨범 연결도 함께 제거한다.

## 일반 폴더 규칙

자산을 일반 폴더에 넣는 것은 `추가`가 아니라 `이동`이다. Library Module은 한 트랜잭션 안에서 해당 자산의 기존 직접 일반 폴더 연결을 모두 제거하고 새 연결 하나를 추가한다. 어느 단계든 실패하면 이전 연결을 그대로 유지한다.

여러 자산의 폴더를 일괄 변경할 때도 모든 대상 자산을 같은 트랜잭션으로 처리한다. 요청한 자산이나 폴더가 없으면 부분 변경을 남기지 않는다.

정확히 같은 자산을 다른 일반 폴더로 다시 수집하면 새 파일이나 자산 레코드를 만들지 않는다. 기존 자산의 일반 폴더를 새로 선택한 폴더로 이동하고 기존 출처와 메타데이터를 보존한다.

일반 폴더를 삭제할 때는 기존 정책을 유지한다. 자식 폴더가 있으면 삭제할 수 없다. 부모가 있는 잎 폴더를 삭제하면 직접 연결된 자산을 부모 폴더로 이동한다. 최상위 잎 폴더를 삭제하면 직접 연결된 자산은 미분류 상태가 된다.

## 기존 다중 연결 처리

마이그레이션 과정에서 모든 기존 다중 일반 폴더 연결을 임의로 정리하지 않는다. 자동 정리는 사용자의 분류 정보를 손실할 수 있기 때문이다.

승인된 일회성 정리는 다음 조건으로 제한한다.

- `만화` 일반 폴더에도 직접 연결된 자산 중 `게임` 일반 폴더에 직접 연결된 자산을 찾는다.
- 대상 개수를 실행 전에 검사하고 예상한 2개가 아니면 정리를 중단한다.
- 예상한 2개라면 해당 자산의 `게임` 직접 연결만 제거한다.
- `만화` 연결과 다른 모든 연결은 유지한다.

이름으로 동작을 분기하는 일반 제품 로직은 만들지 않는다. 위 정리는 스키마 마이그레이션에 넣지 않고 이번 데이터 보정에 한정된 별도 일회성 작업으로 실행한다. 실행 직전에 폴더 이름으로 대상 ID와 자산 목록을 확인하고, 사용자가 승인한 개수 조건을 통과할 때만 해당 ID의 연결을 제거한다. 재사용 가능한 런타임 규칙에는 포함하지 않는다.

## 앨범 규칙

사용자는 최상위 앨범과 하위 앨범을 직접 만들 수 있다. 앨범은 생성, 하위 앨범 생성, 이름 변경, 이동, 아이콘·색상 변경, 삭제를 지원한다.

한 자산은 여러 앨범에 직접 연결될 수 있다. 자산을 앨범에 추가하거나 앨범에서 제거해도 일반 폴더 연결은 변경하지 않는다.

하위 앨범에 직접 연결된 자산은 상위 앨범을 열었을 때도 함께 보인다. 이 포함 관계는 재귀 조회로 계산하며 상위 앨범 연결을 중복 저장하지 않는다. 동일한 자산이 한 상위 앨범의 여러 하위 앨범에 들어 있어도 목록에는 한 번만 표시한다. 첫 버전의 앨범 화면은 항상 모든 하위 앨범을 포함하며, 직접 연결된 자산만 보는 별도 전환 기능은 만들지 않는다.

하위 앨범이 있는 앨범은 삭제할 수 없다. 빈 앨범이나 자산만 담긴 앨범을 삭제하면 앨범 연결만 제거하고 자산, 미디어 파일, 일반 폴더 소속은 보존한다. 앨범을 이동해도 모든 자산 연결은 유지한다.

## 파일과 생명주기

자산 파일은 미디어 금고에 한 번만 저장한다. 일반 폴더와 앨범은 모두 SQLite 메타데이터로 자산을 참조한다. 앨범 수와 관계없이 로컬 파일 용량은 증가하지 않는다.

자산을 라이브러리 휴지통으로 이동하면 앨범 화면에서 숨기되 `asset_albums` 연결은 보존한다. 자산을 복원하면 이전 앨범에 다시 나타난다. 자산을 영구 삭제할 때만 관련 앨범 연결을 함께 제거한다.

앨범에서 자산을 제거하는 동작은 자산 삭제나 휴지통 이동과 명확히 구분한다.

## 사이드바 UX

빠른 보기 아래에 다음 두 섹션을 표시한다.

- `폴더 (N)`: 최상위 일반 폴더 수
- `앨범 (N)`: 최상위 앨범 수

두 섹션은 독립적으로 접고 펼칠 수 있다. 앨범은 일반 폴더와 같은 아이콘, 색상, 선택 배경, 계층 연결선과 키보드 탐색 방식을 사용한다.

앨범 우클릭 메뉴 순서는 다음과 같다.

1. 하위 앨범 만들기
2. 이름 변경
3. 아이콘 및 색상
4. 앨범 이동
5. 삭제

빈 앨범 트리 영역의 우클릭 메뉴와 앨범 섹션 추가 버튼은 최상위 앨범을 만든다. 하위 앨범이 있으면 삭제 항목을 비활성화하고 이유를 표시한다.

## 자산 조작 UX

자산을 일반 폴더에 드롭하면 기존 일반 폴더에서 새 폴더로 이동한다. 자산을 앨범에 드롭하면 일반 폴더 소속을 유지한 채 앨범에 추가한다. 드래그 대상 피드백은 각각 `폴더로 이동`과 `앨범에 추가`로 구분한다.

자산 정보 창은 다음 두 영역을 제공한다.

- `폴더`: 현재 직접 소속 하나를 고르는 단일 선택
- `앨범`: 여러 앨범을 선택할 수 있는 다중 체크 목록

여러 자산을 선택하면 일반 폴더 일괄 이동과 앨범 일괄 추가·제거를 제공한다. 앨범 화면에서는 선택한 자산을 현재 앨범에서 제거할 수 있으며 이 명령은 휴지통 동작과 다른 문구와 아이콘을 사용한다.

## 확장 프로그램

Edge 확장 프로그램의 도넛과 분류 조회 응답에는 일반 폴더만 노출한다. 앨범은 데스크톱 앱에서 수동으로 관리하며 확장 프로그램 수집 대상이 아니다.

확장 프로그램으로 정확한 중복 자산을 다른 일반 폴더에 다시 수집하면 파일을 복제하지 않고 기존 자산의 일반 폴더를 새 폴더로 이동한다.

## 오류 처리와 원자성

- 일반 폴더 이동은 기존 연결 제거와 새 연결 추가를 하나의 트랜잭션으로 처리한다.
- 앨범 일괄 추가·제거는 대상 자산과 앨범을 먼저 검증하고 하나의 트랜잭션으로 처리한다.
- 없는 자산, 일반 폴더 또는 앨범을 요청하면 부분 변경 없이 명시적 오류를 반환한다.
- 앨범 이동은 자기 자신이나 하위 앨범 아래로 이동할 수 없다.
- 하위 앨범이 있는 앨범 삭제는 명시적 오류로 거부한다.
- 일반 폴더 명령은 앨범 테이블을 변경하지 않고 앨범 명령은 일반 폴더 연결을 변경하지 않는다.

## 테스트와 실제 검증

자동 테스트는 다음을 검증한다.

- 자산을 새 일반 폴더에 넣으면 이전 직접 폴더 연결이 제거된다.
- 상위 일반 폴더는 중복 연결 없이 하위 폴더 자산을 포함한다.
- 정확한 중복 재수집은 파일과 자산 레코드를 복제하지 않고 일반 폴더만 이동한다.
- 같은 자산을 여러 앨범에 담아도 파일과 자산 레코드는 하나다.
- 상위 앨범은 모든 하위 앨범의 자산을 중복 없이 반환한다.
- 앨범 추가, 제거, 이동, 삭제는 일반 폴더 소속에 영향을 주지 않는다.
- 휴지통 이동과 복원은 앨범 연결을 보존하고 영구 삭제는 연결을 제거한다.
- 사이드바가 폴더와 앨범을 별도 섹션으로 표시하고 각각 최상위 개수를 센다.
- 우클릭, 키보드 메뉴, 생성, 이름 변경, 이동, 삭제, 아이콘과 색상이 앨범에서도 동작한다.
- 자산 정보 창은 일반 폴더를 단일 선택하고 앨범을 다중 선택한다.
- 여러 자산에 대한 폴더 일괄 이동과 앨범 일괄 추가·제거가 원자적으로 동작한다.
- 일반 폴더 드롭은 이동, 앨범 드롭은 추가 명령을 호출한다.
- 확장 프로그램 분류 응답에 앨범이 포함되지 않는다.
- 승인된 일회성 정리는 예상 대상 2개일 때만 `게임` 연결을 제거한다.

실제 Tauri 창에서는 앨범 생성과 중첩, 자산 추가와 제거, 일반 폴더 이동, 여러 앨범 중복 표시, 상위 앨범 포함 조회, 재시작 후 유지 여부를 확인한다. 검증용 자산이나 앨범을 삭제하기 직전에는 사용자 확인을 받는다.

## 제외 범위

- 규칙이나 검색 조건으로 자동 갱신되는 스마트 폴더
- 앨범에 자산 파일을 물리적으로 복사하는 기능
- 브라우저 확장 프로그램에서 앨범 선택
- 앨범별 독립 자산 메타데이터 복제
- 표지, 설명, 대표 이미지와 전시 배치를 갖는 미래의 컬렉션
- 모든 기존 다중 일반 폴더 연결의 자동 정리
