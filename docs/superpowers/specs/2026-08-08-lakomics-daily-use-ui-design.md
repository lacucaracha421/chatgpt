# Lakomics 일상 사용 UI 설계

날짜: 2026-08-08

상태: 사용자 최종 승인

## 목적

현재 작동하는 이미지 라이브러리를 기능 시연 화면에서 매일 Eagle 대신 사용할 수 있는 Windows 데스크톱 작업 공간으로 발전시킨다. 이번 단계는 이미지 수집·탐색·다중 선택·분류·감상을 매끄럽게 만들며, 기존 미디어 금고·완전 중복·휴지통·백업 규칙을 바꾸지 않는다.

## 범위

### 포함

- Eagle의 구조와 정보 밀도를 참고한 다크 데스크톱 셸
- 전체 자산으로 고정된 시작 화면
- 미분류함
- 파일 드롭을 모든 일반 보기에서 수용
- 드래그 진입·진행·결과 피드백
- 썸네일 크기 조절과 justified-row 가상화
- 다중 선택과 일괄 분류·즐겨찾기·휴지통
- 갤러리 자산과 분류 트리의 내부 드래그
- 앱에서 Windows 탐색기로 선택 자산 복사 드래그
- 큰 이미지 감상 화면과 접이식 정보창
- 진행 중 작업과 실패를 보여주는 접이식 작업 영역
- 기본 키보드 조작과 접근성
- 기존 안전 설정을 사이드바 설정 화면으로 통합

### 제외

- 유사 이미지 검토와 검토 대기 화면의 실제 동작
- 브라우저 확장 프로그램
- 중단 후 수집 재개와 라이브러리 전체 검사
- 영상 관리와 내부 재생
- 컬렉션·전시·꾸미기와 만화 읽기
- 검색, 라이트 모드, 폴더 재귀 수집, 사용자 지정 단축키
- AVIF·HEIC와 Windows 이외의 운영체제
- 계정, 자체 클라우드와 자체 동기화

검토 대기는 장기적인 사이드바 순서상 미분류함·최근·즐겨찾기 다음에 놓이지만, 유사 이미지 단계 전에는 작동하지 않는 빈 항목을 미리 만들지 않는다.

## 시각 방향

- 짙은 회색 배경과 차분한 파란색을 사용한다.
- 강조색은 선택, 주요 동작, 진행과 키보드 포커스에만 쓴다.
- 배경 단계와 1px 테두리로 영역을 나누고 장식용 카드와 큰 빈 테두리를 피한다.
- Windows 기본 제목 표시줄을 유지하고 제품명과 창 제목을 `Lakomics`로 바꾼다.
- `Segoe UI`와 `lucide-react`를 유지한다.
- shadcn·Tailwind·외부 글꼴·모션 라이브러리를 추가하지 않는다.
- 색상, 간격, 글자, 모서리, 높이와 레이어는 의미 기반 CSS 토큰으로 정의한다.

## 화면 구조

### 사이드바

상단 빠른 보기 순서는 다음과 같다.

1. 전체 자산
2. 미분류함
3. 최근
4. 즐겨찾기

그 아래에 사용자 분류 트리를 둔다. 휴지통, 작업과 설정은 사이드바 아래쪽에 분리한다. 설정에는 라이브러리 안전 화면 진입점을 둔다. 사이드바 너비와 펼침 상태는 현재처럼 로컬 환경설정에 보존한다.

### 상단 도구막대

일반 상태에서는 현재 위치, 불러온 자산 수, 정렬, 썸네일 크기와 메타데이터 표시 토글만 둔다. 구체적인 분류에서는 현재 위치 옆에 기존 `이 분류만` 범위 토글을 작게 유지한다. 검색과 안전 설정 버튼은 두지 않는다. 하나 이상의 자산을 선택하면 선택 수, 분류, 즐겨찾기, 휴지통 동작을 제공하는 일괄 작업 도구막대로 전환한다.

### 갤러리

기존 justified-row와 행 가상화를 유지한다. 사용자는 슬라이더로 목표 행 높이를 바꾸고 마지막 값을 저장한다. JPEG·PNG·WebP는 썸네일을 표시하고 GIF는 갤러리에서 정지 썸네일만 표시한다. 메타데이터를 켜면 출처 호스트와 수집일을 낮은 대비로 표시한다.

### 정보창과 감상 화면

정보창은 기본으로 닫혀 있으며 필요할 때 오른쪽에 연다. 선택 자산의 원본 파일명, 출처, 수집일과 연결된 분류를 보여준다. 두 번 클릭하거나 Enter를 누르면 어두운 배경의 큰 감상 화면을 열고, 좌우 방향키로 현재 불러온 순서의 이전·다음 자산을 본다. GIF는 이 화면에서 재생한다.

## 시작과 환경설정

앱을 열면 항상 전체 자산의 첫 페이지를 연다. 마지막 분류나 빠른 보기는 복원하지 않는다. 다음 값은 기억한다.

- 정렬
- 썸네일 목표 높이
- 메타데이터 표시 여부
- 사이드바 너비
- 펼친 분류 항목

저장값이 없거나 잘못됐으면 안전한 기본값을 사용한다.

## 선택 규칙

- 일반 클릭은 기존 선택을 지우고 한 장만 선택한다.
- `Ctrl+클릭`은 한 장을 선택에 추가하거나 제거한다.
- `Shift+클릭`은 마지막 기준점부터 현재 불러온 목록 안의 범위를 선택한다.
- `Ctrl+A`는 현재까지 불러온 자산만 선택한다.
- 빈 공간 클릭과 Escape는 선택을 해제한다. 감상 화면이 열렸다면 Escape는 화면부터 닫는다.
- 방향키는 현재 불러온 목록에서 선택을 이동한다.
- Delete는 선택 자산을 휴지통으로 보낸다.

아직 불러오지 않은 페이지의 자산을 암묵적으로 선택하지 않는다.

## 일괄 작업

여러 자산에 분류를 추가해도 기존 분류를 유지한다. 제거는 별도 동작이며 사용자가 명시한 분류만 제거한다. 여러 자산을 휴지통으로 보내는 변경은 한 번의 라이브러리 작업으로 수행한다. 성공 직후 알림에서 실행 취소할 수 있고, 실행 취소는 같은 자산 ID 집합을 복원한다. 영구 삭제만 확인창을 사용한다.

## 내부 드래그

- 선택된 자산을 분류 항목에 놓으면 선택 전체에 해당 분류를 추가한다.
- 선택되지 않은 자산을 끌기 시작하면 그 자산 한 장만 대상으로 한다.
- 분류 항목을 다른 항목 사이 또는 아래에 놓으면 부모를 변경한다.
- 현재 드롭 대상과 삽입 위치를 색과 선으로 표시한다.
- 자기 자신 또는 자신의 하위로 이동하는 동작은 UI와 라이브러리 양쪽에서 거부한다.
- 키보드 사용자는 동일한 일괄 분류 메뉴와 기존 이동 대화상자를 사용할 수 있다.

Tauri의 Windows 네이티브 파일 드롭과 HTML5 드래그가 충돌하므로 내부 드래그는 HTML5 `draggable`에 의존하지 않고 pointer 이벤트로 구현한다.

## 외부에서 앱으로 드롭

휴지통·설정·복구 중인 화면을 제외한 모든 일반 자산 보기에서 이미지 파일을 받을 수 있다.

- 구체적인 분류 보기: 해당 분류를 함께 저장
- 전체 자산·미분류함·최근·즐겨찾기: 분류 없이 저장하여 미분류함에 나타남
- 분류가 하나라도 연결되면 미분류함에서 자동으로 제외

파일이 창 위에 있으면 화면 전체 오버레이에 저장 목적지와 지원 형식 `JPEG·PNG·GIF·WebP`를 표시한다. Tauri의 `over` 이벤트에는 파일 경로가 없으므로 놓기 전에는 허용 형식을 안내하고, 개별 파일의 실제 형식·폴더 여부는 놓은 직후 검증해 파일별 결과를 보여준다. 완전 중복은 새 자산을 만들지 않는다.

## 앱에서 탐색기로 드래그

자산 파일의 라이브러리 내부 해시 경로는 UI에 노출하지 않는다. Rust 라이브러리 Module이 선택한 정상 자산 ID를 검증하고 원본 파일명을 보존하는 임시 드래그 항목을 준비한다. Windows 네이티브 드래그는 복사 효과만 허용하며 미디어 금고 원본을 이동하거나 삭제하지 않는다.

- 선택된 자산을 끌면 선택 전체를 복사한다.
- 선택되지 않은 자산을 끌면 해당 자산만 복사한다.
- 같은 원본 파일명이 여러 개면 Windows식 번호를 붙여 충돌을 피한다.
- 임시 항목은 성공·취소 뒤 정리하고, 비정상 종료 잔여물은 다음 라이브러리 열기에서 정리한다.
- 네이티브 드래그는 `drag` Rust crate의 copy 모드를 작은 Rust Interface 뒤에서 사용한다.
- 실제 Windows 탐색기에서 원본 파일명, 여러 파일, 취소, 원본 보존을 확인하기 전에는 완료로 간주하지 않는다.

## 작업 영역

사이드바 아래의 작업 행은 진행 중 수집·복사와 실패 개수를 표시한다. 펼치면 현재 세션의 파일별 상태, 오류 이유와 재시도를 보여준다. 이번 단계에서는 앱 종료 뒤 작업 재개를 약속하지 않는다. 영구 작업 기록과 중단 복구는 후속 단계에서 라이브러리 Module에 추가하며, 현재 UI Interface는 그때 교체할 수 있게 작업 표시와 실행 구현을 분리한다.

## Module과 Interface

### `app`

현재 보기, 선택 ID 집합, 감상 화면, 설정·휴지통·작업 패널의 조립만 소유한다.

### `assets`

자산 조회, 가상화, 선택 규칙, 일괄 도구막대, 정보창과 감상 화면을 소유한다. 파일 경로와 SQL을 알지 않는다.

### `classification`

빠른 보기, 분류 트리, 분류 항목 이동과 자산 분류 드롭 대상을 소유한다.

### `ingestion`

Tauri 파일 드롭 이벤트, 드롭 오버레이, FIFO 수집과 세션 작업 상태를 소유한다.

### `drag-out`

프론트엔드는 선택 ID로 네이티브 드래그 시작을 요청하는 작은 Interface만 가진다. Rust Implementation이 경로 검증, 원본명 별칭, copy 모드와 정리를 숨긴다.

### `library`

미분류 조회, 여러 자산의 원자적 분류 변경·휴지통·복원과 네이티브 드래그에 필요한 안전한 자산 해석을 소유한다.

### `shared/ui`와 `styles`

공통 버튼·메뉴·대화상자·토스트·토글·슬라이더·오버레이·접이식 패널과 모든 디자인 토큰을 소유한다. 같은 목적의 화면별 복사본을 만들지 않는다.

## 오류와 동시성

- 보기나 정렬이 바뀐 뒤 도착한 이전 조회는 무시한다.
- 일괄 작업 중 같은 동작을 다시 제출하지 않는다.
- 일괄 저장이 실패하면 화면에서 일부만 성공한 것처럼 제거하지 않는다.
- 드롭 배치는 FIFO로 처리하되 탐색과 스크롤을 막지 않는다.
- 지원하지 않는 파일, 폴더, 권한, 용량 부족과 중복은 파일별로 구분한다.
- 작업 알림은 `aria-live`로 전달하고 포커스를 강제로 빼앗지 않는다.

## 성능과 접근성

- 5만 장 조건에서도 한 번에 100개씩 읽고 보이는 행과 여유 행만 그린다.
- 썸네일 크기 변경은 불러온 자산의 행만 다시 계산하며 DB를 다시 읽지 않는다.
- 다중 선택은 ID 집합으로 관리하고 전체 자산 자료를 복사하지 않는다.
- 모든 아이콘 버튼은 접근 가능한 이름과 툴팁을 가진다.
- 포커스는 `:focus-visible`로 분명하게 표시한다.
- 메뉴와 대화상자는 기존 키보드·포커스 복귀 Interface를 유지한다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.
- 일반 창과 좁은 창에서 영역이 겹치거나 가로 스크롤이 생기지 않는다.

## 완료 조건

- 기존 수집·완전 중복·정렬·분류·즐겨찾기·휴지통·백업 기능을 잃지 않는다.
- 미분류 드롭과 구체적인 분류 드롭이 각각 올바르게 조회된다.
- 다중 선택·일괄 분류·휴지통·실행 취소가 동작한다.
- 썸네일 크기, 정보 토글, 정렬과 사이드바 설정이 재실행 후 유지된다.
- 실제 Windows 탐색기에서 앱으로 파일을 넣고 앱에서 단일·다중 자산 복사본을 꺼낸다.
- 방향키, Ctrl·Shift 선택, Ctrl+A, Enter, Delete와 Escape가 동작한다.
- 자동 테스트와 빌드가 통과하고 목표 규모를 유지하는 가상화 경계를 검증한다.
- 일반·좁은 창의 실제 실행 화면을 사용자가 확인하고 승인한다.
