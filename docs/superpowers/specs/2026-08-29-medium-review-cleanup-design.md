# 중간 우선순위 리뷰 정리 설계

## 범위

다음 네 항목만 순서대로 수정한다.

1. 비디오 준비 실패 뒤 `.pending-*` 임시 폴더 제거
2. 컬렉션 편집·삭제 대화상자의 Escape 이중 닫힘 방지
3. 사이드바 resize 중 preferences 저장 debounce
4. 저장된 라이브러리 경로 자동 복원 실패 시 stale 경로 제거

a11y, quick preview, 빈 영역 클릭, 복사 피드백 등 별도 후속 백로그는 포함하지 않는다.

## 비디오 임시 폴더

비디오 파생 미디어는 `video-media/.pending-<uuid>`에 완성한 뒤 자산별 최종 디렉터리로 원자적으로 이름을 바꾼다. 도구 실행·결과 검증·최종 경로 충돌·`rename` 중 어느 단계가 실패해도 pending 디렉터리를 최선 노력으로 제거한다.

`rename`과 실패 정리를 작은 설치 함수에 모아, 대상 디렉터리가 뒤늦게 생겨 `rename`이 실패하는 경우도 테스트할 수 있게 한다. 삭제 실패는 원래 준비 오류를 바꾸거나 감추지 않는다.

## 컬렉션 오버레이

상위 상세 화면의 전역 Escape 처리기는 표지 뷰어, provider 대화상자뿐 아니라 컬렉션 편집과 삭제 확인 대화상자가 열린 동안에도 `onExit`을 호출하지 않는다. Escape 한 번은 가장 위의 Radix 대화상자만 닫는다.

미읽음 출간 변경을 `take`한 뒤 `onChanged`가 실패해도 effect에서 처리되지 않은 Promise rejection을 만들지 않는다. 화면에 이미 받은 변경 정보는 유지한다.

기존 App 테스트용 gateway의 IGDB/TMDB 연결 조회는 실제 비동기 계약처럼 기본적으로 `Promise<null>`을 반환하게 해, 오버레이 진입 테스트가 mock 누락으로 깨지지 않게 한다.

## 사이드바 저장 debounce

사이드바의 화면 너비는 pointermove마다 로컬 React 상태로 즉시 갱신한다. persisted `UiPreferences.sidebarWidth`는 마지막 너비 변경 뒤 150ms가 지났을 때 한 번만 갱신한다.

다른 preference 필드는 기존 즉시 저장 동작을 유지한다. debounce timer는 새 너비가 들어오거나 workspace가 언마운트되면 취소한다. 너비 제한과 정수 반올림은 기존 `ClassificationSidebar` 경계에서 유지한다.

## stale 라이브러리 경로

`LibraryProvider`는 실제 개방을 수행하고 성공 여부를 반환하는 내부 함수를 사용한다. 자동 복원에서 실패하면, 실패한 경로가 여전히 storage에 저장된 값과 같을 때만 키를 제거한다. 요청 도중 사용자가 다른 경로를 성공적으로 열어 저장값이 바뀐 경우 새 값을 지우지 않는다.

사용자가 설정 화면에서 수동으로 다른 라이브러리를 열다 실패하면 현재 열린 라이브러리와 기존 저장 경로를 유지한다.

## 테스트와 검증

- 강제로 최종 디렉터리 설치를 실패시켜 pending 디렉터리가 남지 않는 Rust 테스트를 먼저 실패시킨다.
- 편집 및 삭제 대화상자에서 Escape가 상위 `onExit`을 호출하지 않는 테스트를 먼저 실패시킨다.
- 빠른 너비 변경 중 storage가 쓰이지 않고 150ms 뒤 마지막 너비만 저장되는 App 테스트를 먼저 실패시킨다.
- 저장 경로 자동 복원 실패 시 키가 제거되고, 수동 전환 실패 시 기존 키가 유지되는 LibraryContext 테스트를 먼저 실패시킨다.
- 각 항목의 관련 테스트를 통과시킨 뒤 전체 `cargo test`와 `npm test`를 실행한다.
- `C:\New_lakomics_assets`는 열거나 변경하지 않는다.
