# 에셋 빠른 확대 미리보기 설계

## 목표

이미지와 GIF 에셋을 전체 화면 뷰어로 열지 않고도 갤러리에서 빠르게 확대해 확인할 수 있게 한다. 기존 더블클릭 뷰어와 영상 호버 재생은 변경하지 않는다.

## 범위

- 이미지와 GIF 타일에만 빠른 미리보기 트리거를 제공한다.
- 영상 타일은 기존 호버 재생을 유지하며 빠른 미리보기 대상에서 제외한다.
- 즐겨찾기, 선택, 드래그, 더블클릭 뷰어 동작은 그대로 유지한다.
- 미리보기 확대율 설정, 확대/축소, 이동, 메타데이터 표시는 포함하지 않는다.

## 상호작용

- 이미지 타일에 포인터를 올리거나 키보드 포커스를 두면 우측 하단에 작은 `+` 버튼이 나타난다.
- `+` 버튼을 약 150ms 동안 호버하거나 포커스하면 빠른 미리보기가 열린다.
- 미리보기는 썸네일이 아니라 기존 원본 에셋 URL을 사용하며 원본 비율을 유지한다. GIF는 애니메이션 상태로 표시한다.
- 포인터가 `+` 버튼을 벗어나거나 버튼이 포커스를 잃으면 닫힌다.
- 갤러리를 스크롤하거나 `Escape`를 누르면 닫힌다.
- 버튼의 포인터 이벤트는 타일 선택, 드래그, 더블클릭 뷰어를 실행하지 않는다.
- 미리보기 자체는 포인터 이벤트를 받지 않아 갤러리 조작을 가로막지 않는다.

## 배치와 시각 디자인

- `+`는 타일 우측 하단의 quiet 아이콘 버튼으로 표시한다. 메타데이터 오버레이가 켜져 있어도 버튼이 그 위에서 식별 가능해야 한다.
- 팝오버는 기본적으로 타일 오른쪽에 배치하고 공간이 부족하면 왼쪽에 배치한다.
- 수직 위치는 트리거 중앙에 맞추되 뷰포트 여백 안으로 제한한다.
- 팝오버 최대 크기는 뷰포트 너비의 55%, 높이의 70%다.
- 팝오버에는 얇은 경계, 작은 모서리 반경, 기존 floating shadow 토큰만 사용한다. 제목, 설명, 장식 애니메이션은 추가하지 않는다.
- 상태 전환은 80~160ms 범위의 opacity 변화만 사용한다.

## 구조와 상태

- `AssetGallery`가 현재 빠른 미리보기 에셋과 트리거 위치를 하나만 관리한다.
- 각 이미지 `AssetTile`은 열기와 닫기 요청만 갤러리에 전달한다.
- 활성 미리보기 하나만 갤러리 바깥 레이어에 렌더링한다. 따라서 가상화된 타일 수와 관계없이 팝오버 DOM은 최대 하나다.
- 위치 계산은 트리거의 `DOMRect`와 현재 뷰포트 크기만 사용한다. 외부 위치 지정 라이브러리는 추가하지 않는다.
- 다른 이미지의 미리보기를 요청하면 기존 미리보기를 즉시 교체한다.
- 타일이 가상화로 제거되거나 갤러리가 스크롤되면 활성 상태를 해제한다.

## 접근성

- 트리거는 실제 `button` 요소이며 에셋 이름을 포함한 접근 가능한 이름을 제공한다.
- 키보드 포커스로 미리보기를 열 수 있다.
- `Escape`로 닫을 수 있다.
- 팝오버 이미지는 같은 에셋 이름을 대체 텍스트로 사용한다.
- 포커스 표시를 제거하지 않는다.

## 오류 처리

- 원본 이미지 로드가 실패하면 팝오버를 닫는다. 별도 오류 토스트는 표시하지 않는다.
- 화면 크기가 매우 작아도 뷰포트 여백과 최대 크기 제한을 적용해 화면 밖으로 넘치지 않게 한다.

## 테스트

- 이미지와 GIF에는 트리거가 있고 영상에는 없는지 검증한다.
- 호버 지연 전에는 닫혀 있고 지연 후 원본 URL 미리보기가 열리는지 검증한다.
- 포인터 이탈, 포커스 이탈, `Escape`, 스크롤에서 닫히는지 검증한다.
- 빠른 미리보기 조작이 선택·드래그·기존 뷰어를 실행하지 않는지 검증한다.
- 트리거 위치에 따라 팝오버가 좌우를 선택하고 뷰포트 안에 제한되는지 검증한다.
- 기존 갤러리와 전체 화면 뷰어 테스트를 함께 실행한다.
