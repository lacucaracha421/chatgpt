# 도넛 UX는 유지하고 브라우저 확장 프로그램은 새로 작성한다

기존 `chromias` 확장 프로그램은 이미지 드래그, 계층형 도넛 선택, 사이트별 원본 이미지 탐색의 행동 참고자료로만 사용하고 코드는 새 프로젝트에 포함하지 않는다. 새 확장 프로그램은 선택한 이미지와 분류 정보를 데스크톱 앱에 전달하고 결과를 표시하는 작은 인터페이스만 가지며, 분류 트리·중복 판단·파일 저장은 데스크톱 앱이 소유한다. 저장은 데스크톱 앱이 실행 중일 때만 허용하고 확장 프로그램에는 오프라인 대기열을 두지 않는다. 기존 구현의 대형 콘텐츠 스크립트와 백그라운드·Python 호스트 사이에 흩어진 책임을 다시 들여오지 않기 위한 결정이다.
