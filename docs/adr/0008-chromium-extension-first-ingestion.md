# Chromium 확장 프로그램을 주 수집 경로로 삼는다

첫 버전의 가장 중요한 수집 경로는 Chrome과 Edge에서 함께 사용할 수 있는 Chromium 확장 프로그램이며, 파일·폴더 끌어놓기를 두 번째 경로로 제공한다. 확장 프로그램은 이미지·GIF 수집에 집중하고 사이트별 영상 주소 탐색, `yt-dlp`, 로그인 쿠키, 탭 캡처 같은 웹 영상 수집은 후속 단계로 미룬다. 다운로드 폴더 감시와 Firefox 지원도 초기 범위에서 제외해 브라우저별 통합 비용을 제한하면서 사용자가 실제로 가장 자주 수행하는 웹 이미지 수집 흐름을 우선한다.
