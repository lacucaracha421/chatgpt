# 두 고리를 재사용하는 단계형 도넛을 사용한다

브라우저 확장 프로그램의 드래그 기반 도넛은 고리를 계속 추가하지 않고 현재 분류와 바로 다음 분류를 보여주는 두 고리만 재사용한다. 선택이 깊어지면 같은 도넛의 내용이 다음 단계로 바뀌고 현재 경로를 함께 표시해, 선택 영역과 글자 크기를 유지하면서 깊이 제한 없이 분류할 수 있게 한다. 분류 항목 위에 약 0.3초 머물렀을 때만 다음 단계로 전환해 커서가 다른 항목을 스쳐 지나가며 화면이 바뀌는 일을 막는다. 가운데 영역으로 커서를 가져오면 한 단계 뒤로 이동하고, 원하는 항목 위에서 마우스를 놓으면 저장하며, 도넛 밖에서 놓거나 `Esc`를 누르면 취소한다. 한 고리에는 항목 7개와 `더보기` 한 칸만 표시해 드래그 중에도 각 조각을 정확히 선택할 수 있게 한다. 표시 순서는 사용자가 고정한 항목, 최근 사용 빈도가 높은 항목, 이름순으로 정한다. `더보기` 위에 머물면 드래그 상태를 유지한 채 같은 고리에 다음 7개와 `이전`을 표시하며, 텍스트 검색은 도넛 밖의 별도 흐름으로 둔다. 한 번의 드래그에서는 하나의 최종 분류 경로만 선택하며, 추가 캐릭터나 태그는 데스크톱 앱에서 나중에 붙인다.
