# 완전 중복은 차단하고 유사 이미지는 사용자가 비교한다

수집하려는 파일 내용이 기존 자산과 완전히 같으면 새 자산 생성을 자동으로 막는다. 다만 기존 자산이 라이브러리 휴지통에 있으면 새 자산을 만들지 않고 기존 분류와 좋아요를 유지한 채 복원할지 묻는다. 기존 관리 정보는 남아 있지만 금고 파일이 사라진 누락 자산이면 동일한 해시를 확인한 뒤 기존 정보와 연결을 유지한 채 자동으로 파일을 복구한다. 파일은 다르지만 시각적으로 유사한 이미지는 오판 가능성이 있으므로 자동 삭제하거나 병합하지 않고, 기존 이미지와 새 이미지의 해상도·파일 크기·형식·출처·분류 정보를 나란히 비교하게 한다. 사용자는 기존 이미지 유지, 새 이미지로 교체, 둘 다 보관 중 하나를 선택하며, 교체할 때 기존 이미지의 태그·컬렉션·작품 연결을 새 이미지가 이어받는다.
