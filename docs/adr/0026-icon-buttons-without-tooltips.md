# 아이콘 버튼에 툴팁을 두지 않고 설정 보기의 버튼 설명으로 모은다

**Status:** Superseded by ADR-0034

이 문서는 모든 아이콘 버튼의 tooltip을 제거하던 초기 PC 규칙의 역사 기록이다. 현재는 모호한 명시적 PC shell icon control에 짧은 비대화형 tooltip을 허용하며, `aria-label`과 키보드 설명 경로를 유지한다. 모든 버튼에 tooltip을 붙이라는 뜻은 아니다.

기존 데스크톱 UI 설계(데일리 사용, 컴팩트 설계)는 "모든 아이콘 버튼은 접근 가능한 이름과 툴팁을 가져야 한다"고 했다. 데일리 감상 UX 개편에서는 툴팁이 마우스 사용자에게만 즉각 도움을 주고 화면 곳곳에서 시각 소음을 만들며, 아이콘만 보고 용도를 몰라 설명이 필요한 사용자는 마우스로 부품 하나씩 찾아야 하는 문제가 있다. 따라서 아이콘 버튼의 툴팁을 제거하고 접근 가능한 이름(aria-label)은 유지하며, 버튼 용도와 단축키 설명은 설정 보기의 [단축키·버튼 설명] 섹션에 정적 표로 모은다. 툴팁은 다시 도입하지 않고 새 버튼도 같은 규칙을 따른다.
