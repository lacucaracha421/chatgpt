# X를 우선하고 Pixiv를 보조하는 출처 어댑터를 만든다

첫 버전의 브라우저 확장 프로그램은 일반 웹 이미지 수집을 기본으로 제공하고, 사이트별 원본 이미지 탐색은 사용 빈도가 가장 높은 X(트위터)를 우선하며 Pixiv를 두 번째로 지원한다. X 게시물에 이미지가 여러 장 있어도 사용자가 드래그한 한 장만 수집하며 전체 게시물 일괄 저장은 제공하지 않는다. 자산에는 출처 URL과 라이브러리에 들어온 수집일만 보존하고 게시물 본문, 작성자 표시 이름, 좋아요·리트윗 수는 저장하지 않는다. 다른 사이트의 썸네일 업그레이드 규칙은 실제 사용 요구가 생길 때 추가해 기존 확장 프로그램의 광범위한 사이트별 복잡성을 다시 들여오지 않는다.
