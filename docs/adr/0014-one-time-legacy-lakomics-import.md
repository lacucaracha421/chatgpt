# 기존 Lakomics 데이터는 한 번 가져오고 형식 호환은 유지하지 않는다

첫 버전은 기존 Lakomics 설치의 원본 이미지, 태그, 좋아요, 제목, 출처와 새 구조에 대응되는 작품 정보를 새 라이브러리로 한 번 가져오는 기능을 제공한다. 기존 SQLite·Isar 형식을 새 앱의 실행 중 저장 형식으로 계속 지원하지 않으며, 썸네일·완전 중복 해시·유사 이미지 해시·캐시·로그는 이전하지 않고 새 앱이 다시 생성한다. 이전은 기존 파일을 이동하거나 삭제하지 않고 새 라이브러리로 복사한 뒤 개수·크기·해시를 검증해 보고하며, 기존 Lakomics 삭제는 사용자가 새 앱을 확인한 뒤 직접 결정한다.
