# 망가 시리즈는 라이브러리 밖 폴더를 참조한다

망가 컬렉션은 사용자가 관리하는 외부 폴더(망가 루트)에 이미 존재하며, 앱이 파일을 복사해 라이브러리로 옮기지 않는다. 앱은 망가 루트 경로를 설정으로 저장하고, 시리즈 폴더와 페이지를 루트 기준 상대 경로로 참조한다. 표지 썸네일만 루트 안 `.lakomics-thumbs/`에 생성해 캐시한다.

라이브러리의 `assets` 테이블이 파일을 소유하고 생명주기를 통제하는 방식(미디어 금고)과 달리, 망가 시리즈는 사용자 폴더의 원본을 그대로 존중한다. 복사본을 만들면 수백 개 시리즈·수만 개 파일의 디스크 사용량이 두 배가 되고, 사용자가 다른 도구로 컬렉션을 갱신해도 앱이 따라가지 못한다. 컬렉션 구조(폴더명, info.txt, 페이지 번호)가 사실상의 진실 원천이며, 앱은 이를 읽는 읽기 전용 뷰어다.
