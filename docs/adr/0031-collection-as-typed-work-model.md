# 컬렉션을 타입별 작품 모델로 재정의하고 외부 메타데이터를 연동한다

이전 ADR-0004, ADR-0012, ADR-0030은 컬렉션을 "자산을 큐레이션하는 그룹"으로 설계하고, 작품(게임·만화·영화)을 분류 트리의 노드로 다뤘다. 이 결정은 레거시 whatthe3에서 이미 "collection = 타입별 메타데이터를 가진 작품 카드"로 동작했던 실사용 경험과 어긋난다.

이제 컬렉션을 게임·만화·영화 작품을 표지·타입별 상세 정보(작가·감독·연도·점수 등)·대표 이미지로 모아보는 단위로 재정의한다. 작품을 위한 별도 엔티티를 만들지 않고 컬렉션 하나로 통합한다. 상세 정보는 SteamDB·IGDB·알라딘·MangaDex·TMDB 같은 외부 서비스에서 가져오며, 가져온 뒤에도 사용자가 직접 고칠 수 있도록 원본 응답과 동기화 시각을 보존한다.

레거시의 폴더 기반 자산 구조(컬렉션 폴더 안에 이미지를 직접 넣는 방식)는 가져오지 않는다. 현재 Lakomics의 자산 중심 미디어 금고 모델(ADR-0001, ADR-0019)을 유지하고, 컬렉션은 기존 자산을 참조만 한다. 레거시 데이터는 별도 마이그레이션 도구로 나중에 옮긴다.

첫 버전은 스키마·CRUD·타입별 메타데이터 수동 입력·쇼케이스를 갖추고, 외부 API 연동은 그 위에 붙인다.
