# 안전 설정을 설정 보기의 [안전] 섹션으로 통합한다

백업·복구 화면을 별도 대화상자로 띄우는 대신 사이드바 하단 [설정] 항목이 콘텐츠 영역에서 여는 설정 보기 안의 [안전] 섹션으로 통합한다. 설정 보기는 [일반 설정](라이브러리 폴더 위치, 앱 버전)과 [단축키·버튼 설명](정적 표)을 함께 두는 일체형 보기이며, 복구 확인·진행·완료 흐름 전체가 [안전] 섹션 안에서 끝나고 복구 중 전체 입력 차단과 드롭 비활성화는 유지한다. 설정 보기에서 Escape는 이전 보기로 복귀한다. 설정을 여러 대화상자로 흩어 두면 진입점과 동작이 불일치하므로 하나의 설정 표면으로 모아 일관성을 유지한다.
