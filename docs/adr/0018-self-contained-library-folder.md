# 라이브러리는 SQLite와 일반 미디어 폴더로 구성한다

사용자가 선택한 하나의 라이브러리 폴더 안에 `library.sqlite`, 원본을 보관하는 `assets/`, 다시 생성할 수 있는 `thumbnails/`, 메타데이터 백업을 보관하는 `backups/`를 둔다. 이미지와 영상의 바이너리는 데이터베이스에 넣지 않고 일반 파일로 저장하며 SQLite에는 작품, 분류, 좋아요, 출처와 상대 경로 같은 메타데이터만 보관해 대용량 파일 처리와 백업·복구를 단순하게 한다. 휴지통에 넣은 자산은 파일을 옮기지 않고 SQLite의 보관 상태만 바꾸며, 사용자가 휴지통을 비우거나 설정된 보존 기간이 지나면 실제 파일을 제거한다.
