# 영상은 원본을 우선 재생하고 필요할 때만 호환 재생본을 만든다

Status: Accepted; supersedes ADR-0016 and the "목록에서는 영상 원본에 접근하지 않는다" constraint in ADR-0015.

이미지 라이브러리의 수집·분류·휴지통·뷰어 기반이 완성됐으므로 Lakomics 안에서 영상 미리보기와 재생을 지원한다. 모든 영상을 일괄 변환하지 않고 Windows WebView2에서 재생 가능한 원본은 구간 전송으로 직접 사용하며, 재생할 수 없는 원본에만 호환 재생본을 만든다. 대표 썸네일과 탐색 프레임을 포함한 파생 미디어는 원본에서 재생성할 수 있고 원본 자산의 생명주기를 따른다.

영상 검사와 파생 미디어 생성은 Rust의 `VideoMedia` Module이 소유한다. Windows용 FFmpeg/FFprobe는 Tauri sidecar로 묶되 GPL 및 nonfree 옵션을 사용하지 않는 재배포 가능한 빌드만 허용하고, 정확한 소스·빌드 설정·라이선스 고지를 배포물과 함께 유지한다. 백그라운드 준비 상태는 SQLite에 기록해 중단 후 재개하며 동시에 하나의 영상만 변환한다.
