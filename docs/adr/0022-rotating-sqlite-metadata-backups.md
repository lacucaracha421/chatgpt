# SQLite 메타데이터 백업을 자동으로 순환 보관한다

앱은 라이브러리 원본 자산을 중복 복사하지 않고 `library.sqlite`만 하루 한 번 자동 백업해 최근 7개를 유지한다. 데이터베이스 구조를 변경하기 전에는 일일 순환과 별도의 백업을 만든다. 복구할 때는 선택한 백업을 먼저 검증하고 현재 데이터베이스도 `복구 직전 백업`으로 보존한 뒤 교체하며, 이후 라이브러리 검사를 실행해 실제 파일과 관리 정보가 맞는지 확인한다. 이를 통해 파일은 남아 있지만 분류·좋아요·작품 연결을 잃거나 잘못된 복구 시점을 선택한 상황에서도 다시 돌아갈 수 있게 한다.
