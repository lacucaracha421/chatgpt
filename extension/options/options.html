Lakomics X Collector

저장 방식

Cloud

이미지·영상·움짤 MP4를 PC를 거치지 않고 Cloud로 바로 보냅니다.

PC 직접 연결

LAN/Tailscale로 PC Lakomics에 바로 저장합니다. 자동 모드에서는 Cloud보다 이 경로를 먼저 시도합니다.

연결 · 동기화 상태

X Translate

AI X Translate Lite v1.4.14 OpenRouter판을 내장합니다. API 제공자·키·모델은 X 화면의 訳 패널에서 설정합니다.

모바일 도넛

현재 화면에 원본 게시물이 남아 있을 때만 자동으로 좋아요를 누릅니다. 이미 좋아요한 게시물은 건드리지 않습니다.

PC · 방사형 메뉴 배치

Lakomics에 연결하면 편집기를 준비합니다.
고급 · 복구 설정

오프라인 저장

Lakomics에 연결되지 않을 때 브라우저의 기본 Download 폴더 아래에 저장합니다. Android의 /storage/emulated/0 같은 절대 경로는 확장 API로 지정할 수 없습니다.

예: Lakomics images → 내장 저장공간/Download/Lakomics images

연결 설정 백업

완전 재설치로 저장소가 초기화될 때만 사용합니다. JSON에는 Lakomics 연결 키가 평문으로 포함됩니다.

오프라인 도넛 분류

PC에 연결되지 않았을 때만 쓰는 로컬 분류입니다. 평소에는 PC Lakomics 분류가 우선됩니다.
